# Obsidian Link

Links ICS events to Obsidian notes.

When invoked, this skill links events from the ICS file to Obsidian notes in
`01-University/01-Subjects/`, creating subject-specific markdown notes with
event metadata.

## Usage

Run `/obsidian-link` to link your university schedule events to Obsidian notes.

## Implementation

```bash
python3 scripts/obsidian_link.py
```

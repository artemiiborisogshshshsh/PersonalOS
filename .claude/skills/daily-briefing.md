# Daily Briefing

Generates a daily briefing note from a template in the 05-Life/Daily-Briefings directory.

When invoked, this script uses the current date to create a new briefing note if one doesn't already exist for that day.

## Usage

Run `/daily-briefing` to generate the daily briefing note for today.
You can also provide a title: `/daily-briefing My Custom Title`

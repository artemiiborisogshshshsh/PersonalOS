# Lint Scripts

Runs flake8 linter on all Python scripts in the `scripts/` directory and reports any issues.

When invoked, this skill installs flake8 if needed, lints the scripts, and prints the results.

## Usage

Run `/lint-scripts` to lint the Python scripts.

# Planning Scenario

Generates a planning scenario note from a template in the 05-Life/Planning-Scenarios directory.

When invoked, this script creates a new planning scenario note for exploring different future possibilities and decisions.

## Usage

Run `/planning-scenario` to generate a planning scenario note.
You can also provide a title: `/planning-scenario Career Change Evaluation`

# Подготовка блоков

Генерирует блоки подготовки в Google Calendar для событий учебного расписания с учётом lead‑time, гибкого поиска свободного окна и AI‑регулирования подготовки. При запуске без переменной окружения DRY_RUN создаёт реальные события в календаре. При установке DRY_RUN запускается в тестовом режиме, выводя действия без изменения календаря. После создания каждого блока подготовки может отправляться HTTP‑уведомление на настроенный вебхук (по умолчанию http://localhost:5678/webhook/test-webhook) через переменную N8N_WEBHOOK_URL.

Когда вызывается, этот навык будет парсить ICS файл, вычислять необходимое время подготовки для каждого события (с возможной корректировкой через AI) и создавая соответствующие блоки подготовки в Google Calendar.

## Использование

Запустите `/prep-blocks <ics_file> [calendar_summary] [lead_time_hours]` для генерации блоков подготовки.

* `ics_file` — путь к файлу ICS с расписанием.
* `calendar_summary` — название целевого календаря в Google Calendar (по умолчанию «University Schedule»).
* `lead_time_hours` — максимальное время перед событием, в течение которого ищется свободное окно для блока подготовки (по умолчанию 2 часа).

## Переменные окружения

* `DRY_RUN` — если установлена (любое значение), запускает скрипт в тестовом режиме без реальных изменений в Google Calendar.
* `N8N_WEBHOOK_URL` — URL вебхука для отправки уведомлений о созданных блоках подготовки (по умолчанию http://localhost:5678/webhook/test-webhook).
* `N8N_AI_WEBHOOK_URL` — URL вебхука n8n, который вызывает AI‑сервис для предложения оптимального времени подготовки (опционально). Если не задан, используется правило‑based расчёт.
* `TELEGRAM_BOT_TOKEN` — токен бота Telegram для отправки уведомлений (опционально).
* `TELEGRAM_CHAT_ID` — ID чата Telegram для отправки уведомлений (опционально).

## Реализация

```bash
python3 scripts/prep_blocks.py "8И41, (31.08.2026 - 13.09.2026).ics"
```

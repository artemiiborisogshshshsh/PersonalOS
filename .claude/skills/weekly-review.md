# Weekly Review

Generates a weekly review note from a template in the 05-Life/Weekly-Reviews directory.

When invoked, this script uses the current date to determine the Monday to Sunday range,
fills in the template, and creates a new note if one doesn't already exist for that week.

## Usage

Run `/weekly-review` to generate the weekly review note for the current week.

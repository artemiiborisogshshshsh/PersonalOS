# HTTP запрос
**HTTP запрос** – работает как официант, переносит от клиента серверу задачу, вкратце они передают метаданные: кто делает запрос, что находится внутри, и как сервер должен отреагировать.
## Заголовки запроса
### Authorization
Нужен для аутентификации пользователя в серверной системе. Используется если проверяет например авторизацию пользователя и появляться обычно после ошибки 401 Unauthorized. Обычно `<схема> <учетные_данные>` есть разные схемы `Bearer` (для JWT-токенов) и `Basic` (логин:пароль в Base64). 

> [!NOTE] Для примера:
> Authorization: Bearer eyJhbGciOiJIUzI1Ni.
### Cookie
Заголовок запроса. Содержит данные, которые сервер ранее прислал в `Set-Cookie`. Нужен, чтобы сервер «узнал» пользователя (например, открыл нужную корзину или активную сессию), так как HTTP сам по себе не помнит предыдущие запросы.

> [!NOTE] Для примера:  
> Cookie: session_id=abc123; theme=dark
### Set-Cookie
Заголовок ответа. Сервер отправляет его браузеру, чтобы тот сохранил информацию (куки) на диске. В нем могут быть указаны параметры безопасности: `HttpOnly` (запрет доступа из JS) или `Expires` (срок жизни).
> [!NOTE] Для примера:  
> Set-Cookie: user_id=42; Max-Age=3600; HttpOnly

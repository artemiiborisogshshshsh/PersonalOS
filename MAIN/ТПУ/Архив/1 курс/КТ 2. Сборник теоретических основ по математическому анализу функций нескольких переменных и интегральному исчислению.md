**Модуль 1.1: Основные понятия функций нескольких переменных (ФНП)**

1.  **Область определения функции нескольких переменных:**

    *   **Определение:** Областью определения функции $z = f(x₁, x₂, ..., x_n)$ называется множество всех точек $(x₁, x₂, ..., x_n)$ из `n`-мерного пространства `Rⁿ`, для которых выражение $f(x₁, x₂, ..., xn)$ имеет смысл и является действительным числом.

    *   **Обозначение:** `D(f)` или `D`.

    *   **Особенности:** В отличие от функций одной переменной, область определения ФНП обычно представляет собой некоторое множество (область) на плоскости (при `n=2`) или в пространстве (при `n=3`). Ограничения могут возникать из-за:

        *   Знаменателей (не должен обращаться в ноль).

        *   Подкоренных выражений четной степени (должны быть неотрицательны).

        *   Логарифмов (аргумент должен быть строго положителен).

        *   Обратных тригонометрических функций (ограниченность аргумента).

        *   Физического или геометрического смысла задачи.

    *   **Пример (n=2):** $f(x, y) = sqrt(1 - x² - y²)$. Область определения: $D(f) = {(x, y) | x² + y² ≤ 1}$ (круг радиуса 1 с центром в начале координат).

2.  **Множество значений функции нескольких переменных:**

    *   **Определение:** Множеством значений функции `z = f(x₁, x₂, ..., xn)` называется множество всех действительных чисел `z`, которые принимает функция при всевозможных значениях аргументов `(x₁, x₂, ..., xn)` из ее области определения `D(f)`.

    *   **Обозначение:** `E(f)` или `E`.

    *   **Особенности:** Определение множества значений для ФНП часто сложнее, чем для функций одной переменной. Оно может быть интервалом, отрезком, лучом или их объединением. Для его нахождения анализируют поведение функции на границах области определения и в критических точках внутри области.

    *   **Пример (n=2):** `f(x, y) = x² + y²`. Множество значений: `E(f) = [0, +∞)`.

3.  **Линии уровня (для n=2) и Поверхности уровня (для n>=3):**

    *   **Определение линии уровня:** Линией уровня функции `z = f(x, y)` называется множество всех точек `(x, y)` на плоскости `Oxy`, в которых функция принимает одно и то же значение `C`: `f(x, y) = C`.

    *   **Определение поверхности уровня:** Поверхностью уровня функции `u = f(x, y, z)` называется множество всех точек `(x, y, z)` в пространстве `Oxyz`, в которых функция принимает одно и то же значение `C`: `f(x, y, z) = C`.

    *   **Смысл:** Линии/поверхности уровня позволяют визуализировать трехмерный (и выше) график функции на плоскости (в пространстве). Они показывают, как изменяется значение функции при движении по плоскости (в пространстве). Чем ближе линии уровня друг к другу, тем быстрее изменяется функция. Аналог - горизонтали на топографической карте.

    *   **Построение:** Для построения линии уровня `f(x, y) = C` нужно задать конкретные значения `C` и построить соответствующие кривые. Для поверхностей уровня - соответствующие поверхности.

4.  **Точки разрыва функции нескольких переменных:**

    *   **Определение:** Точка `M₀(x₁⁽⁰⁾, x₂⁽⁰⁾, ..., xn⁽⁰⁾)` называется точкой разрыва функции `f(M)`, если в этой точке нарушается хотя бы одно из условий непрерывности:

        1.  Функция `f(M)` определена в точке `M₀` (т.е. `M₀ ∈ D(f)`).

        2.  Существует конечный предел функции при стремлении аргумента к точке `M₀` (по любому пути!): `lim_{M→M₀} f(M) = A`.

        3.  Этот предел равен значению функции в точке: `A = f(M₀)`.

    *   **Классификация:** Аналогично функциям одной переменной, разрывы могут быть:

        *   **Устранимые:** Предел существует, но не равен значению функции или функция не определена в точке (но доопределима).

        *   **Неустранимые (1-го рода):** Существуют конечные пределы по разным путям, но они не равны между собой.

        *   **Неустранимые (2-го рода):** Хотя бы один предел по какому-то пути бесконечен или не существует.

    *   **Ключевое отличие от n=1:** Для ФНП предел должен быть *одинаковым* при стремлении к точке `M₀` по *любому* пути в `n`-мерном пространстве. Если хотя бы по двум разным путям пределы разные, то общего предела не существует, и функция разрывна в точке `M₀`.

**Модуль 1.2: Дифференциальное исчисление ФНП (Часть 1)**

1.  **Частные производные первого порядка:**

    *   **Определение (для $z=f(x,y)$):** Частной производной функции $z = f(x, y)$ по аргументу `x` в точке `(x₀, y₀)` называется предел (если он существует):

        $∂f/∂x = ∂z/∂x = lim_(Δx→0) [f(x₀ + Δx, y₀) - f(x₀, y₀)] / Δx$

        Аналогично, частной производной по `y` называется предел:

        $∂f/∂y = ∂z/∂y = lim_(Δy→0) [f(x₀, y₀ + Δy) - f(x₀, y₀)] / Δy$

    *   **Смысл:** Частная производная `∂f/∂x` показывает скорость изменения функции `f` по направлению оси `Ox` (при фиксированном значении остальных переменных). Аналогично для `∂f/∂y`.

    *   **Вычисление:** При нахождении `∂f/∂x` все переменные, кроме `x`, считаются постоянными, и функция дифференцируется по `x` как функция одной переменной. Аналогично для других переменных.

    *   **Обозначения:** `∂f/∂x`, `f'ₓ`, `z'ₓ`, `Dₓf`.

    *   **Геометрический смысл (n=2):** $f'ₓ(x₀, y₀)$ - угловой коэффициент касательной к кривой, полученной сечением графика `z=f(x,y)` плоскостью `y = y₀`, в точке `(x₀, y₀, f(x₀, y₀))`. Аналогично для `f'ᵧ`.

2.  **Касательная плоскость и нормаль к поверхности (для n=2):**

    *   **Уравнение касательной плоскости:** Если функция $z = f(x, y)$ дифференцируема в точке `(x₀, y₀)`, то касательная плоскость к ее графику (поверхности) в точке `(x₀, y₀, z₀)` (где `z₀ = f(x₀, y₀)`) задается уравнением:

        $z - z₀ = f'ₓ(x₀, y₀)(x - x₀) + f'ᵧ(x₀, y₀)(y - y₀)$

    *   **Уравнение нормали:** Нормалью к поверхности в точке называется прямая, проходящая через эту точку перпендикулярно касательной плоскости. Ее канонические уравнения:

        $(x - x₀) / f'ₓ(x₀, y₀) = (y - y₀) / f'ᵧ(x₀, y₀) = (z - z₀) / (-1)$

    *   **Условие дифференцируемости:** Существование частных производных в точке - *необходимое*, но *не достаточное* условие существования касательной плоскости. Необходимо и достаточно, чтобы функция была *дифференцируемой* в точке.

3.  **Дифференциал функции нескольких переменных (первого порядка):**

    *   **Определение:** Главная линейная относительно приращений аргументов часть полного приращения функции называется ее полным дифференциалом (дифференциалом первого порядка).

    *   **Формула (для $z=f(x,y)$):** Если функция дифференцируема в точке `(x, y)`, то ее дифференциал записывается как:

        $dz = df = (∂f/∂x) dx + (∂f/∂y) dy$

        где `dx = Δx`, `dy = Δy` - дифференциалы (приращения) независимых переменных.

    *   **Общий вид ($u=f(x₁,..,x_n)$):** du = $(∂f/∂x₁) dx₁ + (∂f/∂x₂) dx₂ + ... + (∂f/∂xn) dx_n$

    *   **Связь с приращением:** `Δu ≈ du` при малых $dx₁, ..., dx_n$. Дифференциал является основной линейной частью приращения.

    *   **Инвариантность формы:** Форма записи дифференциала `du` не зависит от того, являются ли переменные $x₁, ..., x_n$ независимыми или функциями других переменных (в отличие от производной).

4.  **Производная по направлению:**

    *   **Направляющий вектор:** Задается вектором $l = (lₓ, lᵧ, l_z)$ ($l = (l₁, ..., ln)$ в $Rⁿ$), длина которого $(|l| = sqrt(lₓ² + lᵧ² + l_z²)$) обычно считается равной 1 (орту). Тогда $l = (cosα, cosβ, cosγ)$, где `α, β, γ` - углы между вектором `l` и осями координат (`cosα, cosβ, cosγ` - направляющие косинусы).

    *   **Определение:** Производной функции `u = f(M)` в точке `M₀` по направлению вектора `l` называется предел (если он существует):

        $∂u/∂l |_{M₀} = lim_{s→0⁺} [f(M₀ + s·l) - f(M₀)] / s$

        где `s` - расстояние от точки `M₀` до точки `M` вдоль луча, задаваемого вектором `l`.

    *   **Формула вычисления (через градиент):** Если функция дифференцируема в точке `M₀`, то производная по направлению вычисляется как скалярное произведение градиента функции в точке `M₀` и единичного вектора направления `l`:

        $∂u/∂l |_{M₀} = (grad u)|_{M₀} · l = (∂u/∂x)|_{M₀} * cosα + (∂u/∂y)|_{M₀} * cosβ + (∂u/∂z)|_{M₀} * cosγ$

    *   **Смысл:** Скорость изменения функции в заданном направлении `l`.

    *   **Связь с градиентом:** Градиент указывает направление наибыстрейшего возрастания функции ($cosφ = 1$). Производная по направлению максимальна и равна $|grad (u)|$ именно в направлении градиента. В направлении, противоположном градиенту, производная минимальна и равна $-|grad (u)|$.

5.  **Производные высших порядков:**

    *   **Определение:** Частными производными второго порядка функции $z = f(x, y)$ называются частные производные от ее частных производных первого порядка. Их четыре:

        $∂/∂x (∂f/∂x) = ∂²f/∂x² = f''ₓₓ$

        $∂/∂y (∂f/∂x) = ∂²f/∂x∂y = f''ₓᵧ$

        $∂/∂x (∂f/∂y) = ∂²f/∂y∂x = f''ᵧₓ$

        $∂/∂y (∂f/∂y) = ∂²f/∂y² = f''ᵧᵧ$

    *   **Аналогично определяются производные третьего, четвертого и т.д. порядков.**

    *   **Теорема Шварца (о смешанных производных):** Если смешанные производные $f''ₓ_y$ и $f''ᵧ_ₓ$ непрерывны в некоторой окрестности точки (x₀, y₀), то они равны в этой точке: f''ₓᵧ(x₀, y₀) = f''ᵧₓ(x₀, y₀). Это часто позволяет сократить вычисления.

6.  **Дифференциалы высших порядков:**

    *   **Определение:** Дифференциалом второго порядка $d²u$ функции $u = f(x₁, ..., xn)$ называется дифференциал от ее дифференциала первого порядка `du`, рассматриваемого как функция переменных $x₁, ..., xn$ при условии, что дифференциалы независимых переменных $dx₁, ..., dx_n$ являются постоянными (не меняются при переходе от точки к точке).

    *   **Формула (для $u=f(x,y$)):**

        $d²u = d(du) = d( (∂u/∂x) dx + (∂u/∂y) dy ) = \text{ (раскрываем дифференциал от суммы произведения) }$

        $= [∂/∂x (∂u/∂x) dx + ∂/∂y (∂u/∂x) dy] dx + [∂/∂x (∂u/∂y) dx + ∂/∂y (∂u/∂y) dy] dy =$

        $= (∂²u/∂x²) dx² + (∂²u/∂x∂y) dy dx + (∂²u/∂y∂x) dx dy + (∂²u/∂y²) dy²$

        Если смешанные производные непрерывны (и, следовательно, равны по теореме Шварца), то:

        $d²u = (∂²u/∂x²) dx² + 2 (∂²u/∂x∂y) dx dy + (∂²u/∂y²) dy²$

    *   **Символическая запись:** Формально дифференциал `k`-го порядка можно записать как:

	   $dᵏu = (∂/∂x₁ dx₁ + ∂/∂x₂ dx₂ + ... + ∂/∂xn dxn)ᵏ f$

        где выражение в скобках возводится в степень `k` по правилам алгебры, а затем получившийся "многочлен" применяется к функции `f` (символы `∂/∂xᵢ` становятся операторами дифференцирования).

    Отлично, продолжаем теоретический сборник, переходя к интегральному исчислению и векторному анализу.

**Модуль 1.6: Двойные интегралы (Основы)**

1.  **Расстановка пределов интегрирования по произвольной области:**

    *   **Ключевая задача:** Правильно определить порядок интегрирования и пределы для `x` и `y` в двойном интеграле $∬_D f(x,y) dS$ по области `D`.

    *   **Типы областей:**

        *   **Область типа I (Y-простая):** $D = {(x,y) | a ≤ x ≤ b, φ₁(x) ≤ y ≤ φ₂(x)}$

            *   Интегрируем сначала по `y` (внутренний интеграл) от нижней границы `y = φ₁(x)` до верхней `y = φ₂(x)`.

            *   Затем по `x` (внешний интеграл) от `a` до `b`.

            *   $∬_D f(x,y) dS = ∫_a^b dx ∫_{φ₁(x)}^{φ₂(x)} f(x,y) dy$

        *   **Область типа II (X-простая):** $D = {(x,y) | c ≤ y ≤ d, ψ₁(y) ≤ x ≤ ψ₂(y)}$

            *   Интегрируем сначала по `x` (внутренний интеграл) от левой границы `x = ψ₁(y)` до правой `x = ψ₂(y)`.

            *   Затем по `y` (внешний интеграл) от `c` до `d`.

            *   $∬_D f(x,y) dS = ∫_c^d dy ∫_{ψ₁(y)}^{ψ₂(y)} f(x,y) dx$

    *   **Сложные области:** Если область нельзя отнести к типам I или II, ее разбивают на конечное число подобластей, где применимы указанные выше случаи.

    *   **Совет:** Всегда рисуйте область `D`! Определите точки пересечения граничных кривых. Решите, какой порядок интегрирования удобнее (часто выбор диктуется видом области или функцией `f(x,y)`).

**Модуль 1.7: Двойные интегралы (Применение в декартовых координатах)**

1.  **Восстановление области интегрирования по пределам:**

    *   **Задача:** По заданным пределам в повторном интеграле (например, $∫_a^b dx ∫_{φ₁(x)}^{φ₂(x)} f(x,y) dy$ или $∫_c^d dy ∫_{ψ₁(y)}^{ψ₂(y)} f(x,y) dx$) изобразить на плоскости `Oxy` область `D`, по которой ведется интегрирование.

    *   **Алгоритм:**

        1.  По внешнему интегралу определить диапазон изменения основной переменной (`x` от `a` до `b` или `y` от `c` до `d`).

        2.  Для каждого фиксированного значения основной переменной из этого диапазона, по внутреннему интегралу определить диапазон изменения вспомогательной переменной (`y` от `φ₁(x)` до `φ₂(x)` или `x` от `ψ₁(y)` до `ψ₂(y)`).

        3.  Построить кривые, задающие границы области: `y = φ₁(x)`, `y = φ₂(x)`, `x = a`, `x = b` (для типа I) или `x = ψ₁(y)`, `x = ψ₂(y)`, `y = c`, `y = d` (для типа II).

        4.  Заштриховать область `D`, ограниченную этими кривыми.

    *   **Пример:** Пределы $∫_0^1 dy ∫_y^{\sqrt{y}} f(x,y) dx$ задают область:

        *   `y` от `0` до `1` (внешний интеграл).

        *   Для каждого `y` в `[0,1]`, `x` от `y` до $\sqrt{y}$ (внутренний интеграл).

        *   Границы: `x = y` (прямая), x = $\sqrt{y}$ (парабола `y = x²`), `y=0`, `y=1`.

        *   Область `D` лежит между линиями $y = x²$ и $y = x$ на отрезке `y` от `0` до `1`.

2.  **Вычисление двойного интеграла по произвольной области:**

    *   **Алгоритм:**

        1.  Изобразить область интегрирования `D`.

        2.  Определить тип области (I, II или комбинированная).

        3.  Выбрать удобный порядок интегрирования (часто зависит от вида `f(x,y)` или формы `D`).

        4.  Расставить пределы интегрирования в повторном интеграле согласно выбранному порядку и типу области.

        5.  Вычислить внутренний определенный интеграл по одной переменной, считая другую постоянной.

        6.  Вычислить получившийся внешний определенный интеграл по второй переменной.

    *   **Свойства:** Используют линейность, аддитивность по областям, теорему о среднем, оценку интеграла.

3.  **Применение двойного интеграла (декартовы координаты):**

    Двойной интеграл $∬_D f(x,y) dS$ позволяет вычислить:

    *   **Площадь плоской фигуры:** $S(D) = ∬_D 1 dS$

    *   **Объем цилиндрического тела:** Ограниченного снизу областью `D` в плоскости `Oxy`, сверху - поверхностью $z = f(x,y) ≥ 0$: $V = ∬_D f(x,y) dS$

    *   **Масса плоской пластины:** С переменной поверхностной плотностью $ρ(x,y)$: $m = ∬_D ρ(x,y) dS$

    *   **Статические моменты пластины** относительно осей:

        $Mₓ = ∬_D y * ρ(x,y) dS$

        $Mᵧ = ∬_D x * ρ(x,y) dS$

    *   **Координаты центра тяжести пластины:**

        $x_c = Mᵧ / m = (∬_D x * ρ(x,y) dS) / (∬_D ρ(x,y) dS)$

        $y_c = Mₓ / m = (∬_D y * ρ(x,y) dS) / (∬_D ρ(x,y) dS)$

    *   **Моменты инерции пластины** относительно осей и начала координат:

        $Iₓ = ∬_D y² * ρ(x,y) dS$

        $Iᵧ = ∬_D x² * ρ(x,y) dS$

        $I₀ = Iₓ + Iᵧ = ∬_D (x² + y²) * ρ(x,y) dS$

**Модуль 1.8: Двойные интегралы в полярных координатах**

1.  **Переход к полярным координатам:**

    *   **Связь с декартовыми:** `x = r cos φ`, `y = r sin φ`, где `r ≥ 0` (расстояние от начала координат), `φ ∈ [0, 2π)` (угол).

    *   **Якобиан перехода:** Определитель матрицы Якоби преобразования равен `r`:

   $$|∂(x,y)/∂(r,φ)| = |cosφ -r sinφ| = r(cos²φ + sin²φ) = r$$

                  $|sinφ \text{ } r \text{ } cosφ|$

    *   **Формула замены переменных:**

        $$∬_D f(x,y) dx dy = ∬_D f(r cos φ, r sin φ) * |r| dr dφ = ∬_D f(r cos φ, r sin φ) * r dr dφ$$

        (модуль якобиана `|r|` равен `r`, так как `r ≥ 0`).

    *   **Область `D'` в полярных координатах:** Нужно переписать границы области `D` на плоскости `Oxy` в терминах `r` и `φ`. Типичные области: круги, кольца, их сектора.

2.  **Вычисление двойного интеграла в полярных координатах:**

    *   **Алгоритм:**

        1.  Перейти к полярным координатам: `x = r cos φ`, `y = r sin φ`.

        2.  Подставить в подынтегральную функцию: `f(x,y) → f(r cos φ, r sin φ)`.

        3.  Заменить элемент площади: `dx dy → r dr dφ`.

        4.  Определить область `D'` в координатах `(r, φ)`.

        5.  Расставить пределы интегрирования для `r` и `φ` по области `D'`.

        6.  Вычислить повторный интеграл $∬_D f(r cos φ, r sin φ) * r dr dφ$.

    *   **Когда удобно:** Если область `D` - круг, кольцо, их часть, или подынтегральная функция содержит $x² + y²$.

3.  **Применение двойного интеграла (полярные координаты):**

    Формулы для площади, объема, массы, моментов и центра тяжести остаются теми же, но вычисление ведется в полярных координатах с элементом площади $dS = r dr dφ$:

    *   $S(D) = ∬_D' r dr dφ$

    *   $m = ∬_{D'} ρ(r cos φ, r sin φ) * r dr dφ$

    *   $x_c = (∬_{D'} r cos φ * ρ(r cos φ, r sin φ) * r dr dφ) / m$

    *   $y_c = (∬_D' r sin φ * ρ(r cos φ, r sin φ) * r dr dφ) / m$

    *   $I₀ = ∬_D' (r²) * ρ(r cos φ, r sin φ) * r dr dφ \text{   (так как x² + y² = r²)}$

    *   **Связь с декартовыми:** `x = r cos φ`, `y = r sin φ`, `z = z`.

        *   `r ≥ 0` (расстояние до оси `Oz`),

        *   `φ ∈ [0, 2π)` (азимутальный угол - угол в плоскости `Oxy`),

        *   `z ∈ (-∞, +∞)` (аппликата).

    *   **Якобиан перехода:** $|∂(x,y,z)/∂(r,φ,z)| = r$

    *   **Формула замены в тройном интеграле:**

        $∭_Ω f(x,y,z) dV = ∭_Ω f(r cos φ, r sin φ, z) * r dr dφ dz$

    *   **Геометрия:** Название происходит от координатных поверхностей: `r = const` - цилиндр, `φ = const` - полуплоскость, `z = const` - плоскость.

2.  **Сферические координаты:**

    *   **Связь с декартовыми:** `x = ρ sin θ cos φ`, `y = ρ sin θ sin φ`, `z = ρ cos θ`.

        *   `ρ ≥ 0` (расстояние от начала координат),

        *   `θ ∈ [0, π]` (зенитный угол - угол с осью `Oz`),

        *   `φ ∈ [0, 2π)` (азимутальный угол - угол в плоскости `Oxy`).

    *   **Якобиан перехода:** $|∂(x,y,z)/∂(ρ,θ,φ)| = ρ² sin θ$

    *   **Формула замены в тройном интеграле:**

$$ ∭_Ω f(x,y,z) dV = ∭_Ω f(ρ sin θ cos φ, ρ sin θ sin φ, ρ cos θ) * ρ² sin θ dρ dθ dφs$$

    *   **Геометрия:** Координатные поверхности: `ρ = const` - сфера, `θ = const` - конус, `φ = const` - полуплоскость.

3.  **Выбор координат:**

    *   **Цилиндрические:** Удобны для областей, симметричных относительно оси `Oz` (цилиндры, конусы) или если проекция на `Oxy` - круг/кольцо.

    *   **Сферические:** Удобны для областей, симметричных относительно начала координат (шары, шаровые слои) или если границы заданы сферами/конусами.

**Модуль 1.13: Криволинейные интегралы и поверхностные интегралы второго типа**

1. **Условия независимости криволинейного интеграла от пути (плоский случай):** 

   Для векторного поля \($\vec{F} = (P(x,y), Q(x,y))$\) интеграл \($\int_L P\,dx + Q\,dy$\) не зависит от пути \(L\) в односвязной области \(D\) тогда и только тогда, когда выполняется: 

   $$\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}$$

   Эквивалентные условия: 

   - \($∮_CP dx+Q dy=0$) для любого замкнутого контура \($C \subset D$\) 

   - \($\vec{F}$\) потенциально: существует \(u(x,y)\) такая, что \($du = P\,dx + Q\,dy$\) 

2. **Ориентация поверхности:** 

   - Гладкая поверхность \(S\) **ориентируема**, если на ней можно задать непрерывное поле единичных нормалей \($\vec{n}$\) 

   - **Сторона поверхности** определяется выбором направления \($\vec{n}$\): 

     $\vec{n} = \pm \frac{\vec{r}_u \times \vec{r}_v}{|\vec{r}_u \times \vec{r}_v|} \quad \text{(параметризация)}$ 

     $\vec{n} = \pm \frac{(-\frac{\partial z}{\partial x}, -\frac{\partial z}{\partial y}, 1)}{\sqrt{1 + \left(\frac{\partial z}{\partial x}\right)^2 + \left(\frac{\partial z}{\partial y}\right)^2}} \quad \text{(явное задание \(z=z(x,y)\))}$ 

   - **Положительная ориентация** замкнутой поверхности: внешняя нормаль (\($\vec{n}$\) направлен наружу) 

3. **Поверхностный интеграл второго типа (поток):** 

   $$\iint_S \vec{F} \cdot d\vec{S} = \iint_S (P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy)$$

   **Сведение к двойному интегралу** (для ($S: z = z(x,y)$), ($(x,y) \in D)$): 

   $\iint_S R\,dx\,dy = \pm \iint_D R(x,y,z(x,y))\,dx\,dy$

   где знак \(+\) соответствует согласованной ориентации (\($\vec{n}$\) с положительной \(z\)-компонентой). 

   **Общая формула**: 

$$\iint_S \vec{F} \cdot d\vec{S} = \iint_D \vec{F} \cdot \vec{n} \cdot |\vec{r}_u \times \vec{r}_v|\,du\,dv$$
**Модуль 1.14: Основные теоремы векторного анализа**

1. **Дивергенция (расходимость) векторного поля:** 

  $$\text{div}\,\vec{F} = \nabla \cdot \vec{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}$$

   Физический смысл: мощность источника/стока в точке. 

2. **Ротор (вихрь) векторного поля:** 

   $$\text{rot}\,\vec{F} = \nabla \times \vec{F} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\\frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\P & Q & R\end{vmatrix}$$

   Физический смысл: локальное вращение поля. 

3. **Теорема Остроградского-Гаусса:** 

   $$\iiint_V (\nabla \cdot \vec{F})\,dV = \iint_{\partial V} \vec{F} \cdot d\vec{S}$$

   где \($\partial V$\) — замкнутая поверхность, ограничивающая объем \(V\), с внешней ориентацией. 

4. **Теорема Стокса:** 

  $$\iint_S (\nabla \times \vec{F}) \cdot d\vec{S} = \oint_{\partial S} \vec{F} \cdot d\vec{r}$$

   где \($\partial S$\) — граница поверхности \(S\) с согласованной ориентацией (правило правой руки).

**Модуль 1.15: Специальные векторные поля**

1. **Соленоидальное (вихревое) поле:** 

  $$\text{div}\,\vec{F} = 0 \quad \text{во всех точках}$$

   Свойства: линии тока замкнуты, поток через замкнутую поверхность = 0. 

2. **Потенциальное (безвихревое) поле:** 

$$\text{rot}\,\vec{F} = 0 \quad \text{в односвязной области}$$

   Эквивалентно: \($\vec{F} = \nabla u$\) (существует потенциал \(u\)). 

3. **Поиск потенциала:** 

   - **На плоскости**: 
$$u(x,y) = \int_{x_0}^x P(t,y_0)\,dt + \int_{y_0}^y Q(x,t)\,dt + C$$

   - **В пространстве**: 

$$u(x,y,z) = \int_{x_0}^x P(t,y_0,z_0)\,dt + \int_{y_0}^y Q(x,t,z_0)\,dt + \int_{z_0}^z R(x,y,t)\,dt + C$$

4. **Гармоническое поле:** 

   Одновременно потенциальное и соленоидальное: 

   $$\Delta u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} = 0$$

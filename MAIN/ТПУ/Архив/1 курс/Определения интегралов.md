## 1. Определённый интеграл

**Определение:** Пусть функция $f(x)$ определена на отрезке $[a,b]$. Разобьем отрезок $[a,b]$ на $n$ частей точками:

$$a = x_0 < x_1 < x_2 < \ldots < x_{n-1} < x_n = b$$

В каждом частичном отрезке $[x_{i-1}, x_i]$ выберем произвольную точку $\xi_i$ и составим интегральную сумму:

$$I_n(x_i, \xi_i) = \sum_{i=1}^{n} f(\xi_i) \Delta x_i$$
где $\Delta x_i = x_i - x_{i-1}$.
Пусть
$$\lambda = \max_{1 \leq i \leq n} \left| [x_{i-1}, x_i] \right|$$
Число $I$ называется пределом интегральных сумм $I_n (x_i, \xi_i)$ при $\lambda \to 0$, если: ∀ ε > 0 ∃ δ > 0: $\forall$ разбиения отрезка $[a, b]$, с $\lambda < \delta$, ∀{ξi} выполняется неравенство$$|I_n (x_i, \xi_i) - I| < \varepsilon$$Если существует предел интегральных сумм $I_n (x_i, \xi_i)$ при $\lambda \to 0$, то его называют определённым интегралом от функции $f(x)$ на отрезке $[a, b]$ (или в пределах от $a$ **до** $b$).
$$I = \int_a^b f(x)\,dx = \lim_{\lambda \to 0} I_n (x_i, \xi_i)$$

## 2. Двойной интеграл

**Определение:** Пусть $(\sigma)$ — квадрируемая область в плоскости $xOy$, и функция $f(x,y)$ определена на $(\sigma)$.

1. Разобьём $(\sigma)$ на $n$ частей без общих внутренних точек: $\Delta \sigma_1, \dots, \Delta \sigma_n$.
2. В каждой $\Delta \sigma_i$ выберем точку $P_i(\xi_i, \eta_i)$ и составим сумму, назовем ее интегральной суммой для функции $f(x, y)$ по области $\sigma_i$, где $\Delta \sigma_i$ – площадь этой области:

$$I_n = \sum_{i=1}^n f(P_i) \cdot \Delta \sigma_i$$
**Диаметром множества $G$** называется наибольшее расстояние между его точками.  Пусть $d_i = \text{диаметр } \Delta \sigma_i$, $$\lambda = \max_{1 \le i \le n} d_i$$Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$Если предел существует, его называют **двойным интегралом**$$\iint\limits_{(\sigma)} f(x,y) \, d\sigma = \iint\limits_{(\sigma)} f(x,y) \, dx \, dy$$

## 3. Тройной интеграл

**Определение:** Пусть $(V)$ — кубируемая область в пространстве $Oxyz$, и функция $f(x,y,z)$ определена на $(V)$.

1. Разобьём $(V)$ на $n$ частей: $\Delta V_1, \dots, \Delta V_n$.
2. В каждой $\Delta V_i$ выберем точку $P_i(\xi_i, \eta_i, \zeta_i)$ и составим сумму, назовем ее интегральной суммой для функции $f(x, y, z)$ по области $V$,  где $\Delta V_i$ – объем области:
$$I_n = \sum_{i=1}^n f(P_i) \cdot \Delta V_i$$
Пусть $\lambda = \max (\text{диаметров } \Delta V_i)$. 
Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$Если предел существует, его называют **тройным интегралом**
$$\iiint\limits_{(V)} f(x,y,z) \, dV = \lim_{\lambda \to 0} I_n$$

## 4. Криволинейный интеграл I рода
**Определение:** Пусть $(\ell)$ — спрямляемая кривая (имеющая длину) в $Oxyz$, и функция $f(x,y,z)$ определена на $(\ell)$.

1. Разобьём кривую на $n$ дуг: $\Delta \ell_1, \dots, \Delta \ell_n$.
2. На каждой $\Delta \ell_i$ выберем точку $P_i(ξ_i;η_i;ζ_i)$ и составим сумму, назовем ее интегральной суммой для функции $f(x, y, z)$ по кривой $l$,  где $\Delta \ell_i = \text{длина дуги}$:
$$I_n = \sum_{i=1}^n f(P_i) \cdot \Delta \ell_i$$

Пусть $$\lambda = \max_{1 \le i \le n} \Delta \ell_i$$
Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$
Если предел существует, его называю криволинейным интегралом I рода
$$\int_{\ell} f(x,y,z) \, dl = \lim_{\lambda \to 0} I_n$$
**Свойство:** Не зависит от направления обхода.

## 5. Криволинейный интеграл II рода

**Определение:** Пусть $(\ell) = (L_1L_2)$ — простая (точки не повторяются),  спрямляемая кривая в $Oxyz$, и функция $P(x,y,z)$ определены на $(\ell)$.

1. Разобьём кривую точками на n частей $$M_0 = L_1, M_1, \dots, M_n = L_2$$
2. Пусть $M_i(x_i, y_i, z_i)$. Обозначим $\Delta x_i = x_i - x_{i-1}$ (т. е. проекцию дуги ($M_{i-1}M_i$) на ось $Ox$)
3. На каждой. дуге $M_{i-1}M_i$ выберем точку $K_i(\xi_i, \eta_i, \zeta_i)$ и составим сумму, назовем ее интегральной суммой для функции $P(x, y, z)$ по кривой $l$ по переменной $x$:
$$I_n = \sum_{i=1}^n P(K_i)\Delta x_i$$

Пусть $\lambda = \max (\text{длин дуг})$ то есть:
$$\lambda = \max_{1 \le i \le n} \Delta M_{i-1}M_i$$

Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$Если предел существует, его называю криволинейным интегралом II рода
$$\int_{\ell} P \, dx + Q \, dy + R \, dz = \lim_{\lambda \to 0} I_n$$
**Свойство:** Зависит от направления обхода.

## 6. Поверхностный интеграл I рода

**Определение:** Пусть $(S)$ — квадрируемая поверхность в пространстве $Oxyz$, и функция $u=f(x,y,z)$ определена на $(S)$.
1. Разобьём поверхность на n частей: $\Delta S_1, \dots, \Delta S_n$.
2. На каждой $\Delta S_i$ выберем точку $P_i(\xi_i, \eta_i, \zeta_i)$ и составим сумму, назовем ее интегральной суммой для функции $f(x, y, z)$ по поверхности $S$, где $\Delta S_i = \text{площадь}$:
$$I_n = \sum_{i=1}^n f(P_i) \cdot \Delta S_i$$
Пусть d – диаметр $\Delta S_i$  $$\lambda = \max_{1 \le i \le n} d_i$$Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$Если предел существует, его называю поверхностный интегралом I рода
$$\iint\limits_{(S)} f(x,y,z) \, dS = \lim_{\lambda \to 0} I_n$$

## 7. Поверхностный интеграл II рода

**Определение:** Пусть $(S)$ — двусторонняя ориентированная поверхность, и функции $R(x, y, z)$ определены на $(S)$.

1. Разобьём поверхность на части: $\Delta S_1, \dots, \Delta S_n$.
2. В каждой области выберем произвольную точку $K_i(\xi_i, \eta_i, \zeta_i)$
3. $\Delta S_{i(xy)}$ — площадь проекции на $xOy$ со знаком "+" если угол между нормалью выбранной на $S$ в точке $M_i$ и $Oz$ острый, в обратном случае "-".
4. Составим сумму, назовем ее интегральной суммой для функции $R(x, y, z)$ по поверхности $S$ по переменной $x$ и $y$:
Пусть d – диаметр $\Delta S_i$  $$\lambda = \max_{1 \le i \le n} d_i$$
$$I_n = \sum_{i=1}^n R(K_i) \Delta S_{i(xy)}$$

Число $I$ называется **пределом интегральных сумм** при $\lambda \to 0$, если: $\forall \varepsilon > 0 \; \exists \delta > 0 : \forall \text{ разбиений с } \lambda < \delta \text{ и } \forall \{P_i\} \;$.$$|I_n - I| < \varepsilon$$Если предел существует, его называю поверхностный интегралом II рода

$$\iint\limits_{(S)} P \, dy \, dz + Q \, dz \, dx + R \, dx \, dy = \lim_{\lambda \to 0} I_n$$
**Примечание:** Знак проекции определяется углом между нормалью и осью координат.

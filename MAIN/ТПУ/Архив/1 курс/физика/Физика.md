**1. Молекулярно-Кинетическая Теория (МКТ) - Фундамент**

*   **Физическая суть:** МКТ объясняет макроскопические свойства вещества через движение микрочастиц. Основные положения:
    1.  Вещество состоит из частиц.
    2.  Частицы в непрерывном хаотическом движении.
    3.  Частицы взаимодействуют.
    4.  Для идеального газа: размерами частиц пренебрегаем; взаимодействие - только при упругих соударениях.
*   **Основные формулы и связи:**
    *   **Основное уравнение МКТ идеального газа:**
        $$p = \frac{1}{3} n m_0 \langle v^2 \rangle$$
        *   $p$ - давление, $n = N/V$ - концентрация, $m_0$ - масса молекулы, $\langle v^2 \rangle$ - средний квадрат скорости.
    *   **Связь с температурой:**
        $$\frac{3}{2} kT = \frac{1}{2} m_0 \langle v^2 \rangle = \langle E_k \rangle$$
        *   $k$ - постоянная Больцмана, $T$ - абсолютная температура, $\langle E_k \rangle$ - средняя кинетическая энергия.
    *   **Следствие (уравнение состояния):**
        $$p = nkT \quad \text{или} \quad pV = \nu RT$$
        *   $\nu$ - количество вещества, $R$ - универсальная газовая постоянная.
    *   **Средняя квадратичная скорость:**
        $$v_{kv} = \sqrt{\langle v^2 \rangle} = \sqrt{\frac{3kT}{m_0}} = \sqrt{\frac{3RT}{M}}$$
        *   $M$ - молярная масса.

**2. Распределение Максвелла (по скоростям)**

*   **Физическая суть:** Описывает распределение скоростей молекул в газе при термодинамическом равновесии.
*   **Функция распределения:**
    $$f(v) dv = 4\pi \left( \frac{m_0}{2\pi kT} \right)^{3/2} v^2 \exp\left(-\frac{m_0 v^2}{2kT}\right) dv$$
    *   $f(v) dv$ - вероятность скорости в интервале $[v, v+dv]$.
*   **Характерные скорости:**
    *   **Наиболее вероятная:**
        $$v_v = \sqrt{\frac{2kT}{m_0}} = \sqrt{\frac{2RT}{M}}$$
    *   **Средняя арифметическая:**
        $$\langle v \rangle = \sqrt{\frac{8kT}{\pi m_0}} = \sqrt{\frac{8RT}{\pi M}}$$
    *   **Средняя квадратичная:**
        $$v_{kv} = \sqrt{\langle v^2 \rangle} = \sqrt{\frac{3kT}{m_0}} = \sqrt{\frac{3RT}{M}}$$
    *   **Соотношение:** $v_v : \langle v \rangle : v_{kv} = \sqrt{2} : \sqrt{8/\pi} : \sqrt{3}$

**3. Распределение Больцмана (по координатам в поле сил)**

*   **Физическая суть:** Распределение частиц в пространстве при наличии внешнего силового поля.
*   **Формулировка:**
        $$n = n_0 \exp\left(-\frac{E_p}{kT}\right)$$
        *   $n$ - концентрация в точке с $E_p$, $n_0$ - концентрация при $E_p=0$.
*   **Барометрическая формула:**
        $$p = p_0 \exp\left(-\frac{m_0 g z}{kT}\right) = p_0 \exp\left(-\frac{M g z}{RT}\right)$$
        $$n = n_0 \exp\left(-\frac{m_0 g z}{kT}\right) = n_0 \exp\left(-\frac{M g z}{RT}\right)$$

**4. Тепловые машины. Циклы. КПД. Цикл Карно.**

*   **Физическая суть:** Устройство, преобразующее теплоту в работу циклически.
*   **Первый закон термодинамики для цикла:**
        $$A = Q_1 - |Q_2|$$
        *   $Q_1$ - тепло от нагревателя ($Q_1 > 0$), $Q_2$ - тепло холодильнику ($Q_2 < 0$), $A$ - полезная работа.
*   **КПД тепловой машины:**
        $$\eta = \frac{A}{Q_1} = 1 - \frac{|Q_2|}{Q_1}$$
*   **Цикл Карно:**
    *   Состоит из двух изотерм и двух адиабат.
    *   **КПД цикла Карно:**
        $$\eta_{\text{карно}} = 1 - \frac{T_2}{T_1}$$
        *   $T_1$ - температура нагревателя, $T_2$ - температура холодильника ($T_1 > T_2$).
    *   **Связь теплот:**
        $$\frac{|Q_2|}{Q_1} = \frac{T_2}{T_1}$$

**5. Изопроцессы идеального газа**

*   **Изотермический процесс ($T = \text{const}$):**
    *   **Уравнение:**
        $$pV = \text{const} \quad \text{(Закон Бойля-Мариотта)}$$
    *   **Первое начало термодинамики:** $\Delta U = 0 \Rightarrow Q = A$
    *   **Работа газа:**
        $$A = \int_{V_1}^{V_2} p  dV = \nu RT \ln\frac{V_2}{V_1} = \nu RT \ln\frac{p_1}{p_2}$$
*   **Изобарный процесс ($p = \text{const}$):**
    *   **Уравнение:**
        $$\frac{V}{T} = \text{const} \quad \text{(Закон Гей-Люссака)}$$
    *   **Первое начало термодинамики:** $Q = \Delta U + A$
    *   **Работа газа:**
        $$A = p(V_2 - V_1) = p \Delta V$$
*   **Изохорный процесс ($V = \text{const}$):**
    *   **Уравнение:**
        $$\frac{p}{T} = \text{const} \quad \text{(Закон Шарля)}$$
    *   **Первое начало термодинамики:** $A = 0 \Rightarrow Q = \Delta U$
*   **Изменение внутренней энергии (для всех процессов):**
        $$\Delta U = \frac{i}{2} \nu R \Delta T$$
        *   $i$ - число степеней свободы молекулы.

**Сводная таблица изопроцессов:**

| Процесс      | Условие          | Закон                | Работа газа (`A`)     | Первое начало (`Q = ΔU + A`) |
| :----------- | :--------------- | :------------------- | :-------------------- | :--------------------------- |
| **Изотерма** | $T=\text{const}$ | $pV = \text{const}$  | $\nu RT \ln(V_2/V_1)$ | $Q = A$ ($\Delta U = 0$)     |
| **Изобара**  | $p=\text{const}$ | $V/T = \text{const}$ | $p(V_2 - V_1)$        | $Q = \Delta U + p\Delta V$   |
| **Изохора**  | $V=\text{const}$ | $p/T = \text{const}$ | $0$                   | $Q = \Delta U$               |

**Взаимосвязь тем:**
1.  **МКТ -> Максвелл:** Распределение Максвелла дает полную картину распределения скоростей, дополняя МКТ.
2.  **МКТ -> Больцман:** Распределение Больцмана расширяет МКТ на случай внешних полей.
3.  **Максвелл <-> Больцман:** Оба содержат экспоненту Больцмана $\exp(-E / kT)$ (для $E_k$ и $E_p$ соответственно).
4.  **МКТ -> Изопроцессы:** Уравнение состояния $pV = \nu RT$ - следствие МКТ.
5.  **Изопроцессы -> Тепловые машины:** Циклы состоят из последовательности процессов.
6.  **Тепловые машины (Карно) -> МКТ/Температура:** КПД Карно $\eta = 1 - T_2/T_1$ связывает эффективность с температурами, которые являются мерой средней кинетической энергии молекул.

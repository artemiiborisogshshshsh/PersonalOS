## Задача 1: Суммы и XOR-ы на отрезках

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Префиксные суммы (Prefix Sums)** |
| **Зачем** | Быстрые запросы суммы/XOR на отрезке за O(1) |
| **Почему** | Наивный подход O(n·m) не пройдёт при n,m=5·10⁵ |
| **Ключевая идея** | `sum[l..r] = prefix[r] - prefix[l-1]` |
| **Для XOR** | `xor[l..r] = prefix[r] ^ prefix[l-1]` (свойство x^x=0) |

**Почему это работает:**
``` 
prefix[i] = a[0] + a[1] + ... + a[i-1]

Сумма на [l, r]:
prefix[r] = a[0] + ... + a[l-2] + a[l-1] + ... + a[r-1]
prefix[l-1] = a[0] + ... + a[l-2]
─────────────────────────────────────────────────────
prefix[r] - prefix[l-1] = a[l-1] + ... + a[r-1] ✅
```

### 💻 Код (Python)

```python
import sys

def solve():
    input = sys.stdin.readline
    
    n = int(input())
    a = list(map(int, input().split()))
    
    # Префиксные массивы
    prefix_sum = [0] * (n + 1)
    prefix_xor = [0] * (n + 1)
    
    for i in range(n):
        prefix_sum[i + 1] = prefix_sum[i] + a[i]
        prefix_xor[i + 1] = prefix_xor[i] ^ a[i]
    
    m = int(input())
    
    for _ in range(m):
        q_type, l, r = map(int, input().split())
        
        if q_type == 1:
            print(prefix_sum[r] - prefix_sum[l - 1])
        else:
            print(prefix_xor[r] ^ prefix_xor[l - 1])

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n + m) | **Память:** O(n)
## Задача 2: 2D суммы

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **2D префиксные суммы** |
| **Зачем** | Запросы суммы в прямоугольнике за O(1) |
| **Почему** | Наивный O(k·n·m) ≈ 10¹¹ операций не пройдёт |
| **Ключевая идея** | Принцип включений-исключений в 2D |
| **Формула** | `sum = P[y2][x2] - P[y1-1][x2] - P[y2][x1-1] + P[y1-1][x1-1]` |

**Почему это работает:**
```
┌─────────────────────────────┐
│  y1-1         y2            │
│  ┌───────────┬───────────┐  │
│  │     A     │     B     │  │ x1-1
│  ├───────────┼───────────┤  │
│  │     C     │  TARGET   │  │ x2
│  └───────────┴───────────┘  │
└─────────────────────────────┘

TARGET = P[y2][x2]           # Всё (A+B+C+TARGET)
       - P[y1-1][x2]         # Вычесть (A+B)
       - P[y2][x1-1]         # Вычесть (A+C)
       + P[y1-1][x1-1]       # Добавить A (вычли дважды!)
```

### 💻 Код (Python)

```python
import sys

def solve():
    input = sys.stdin.readline
    
    n, m, k = map(int, input().split())
    
    # Префиксная матрица (n+1) × (m+1)
    prefix = [[0] * (m + 1) for _ in range(n + 1)]
    
    for y in range(1, n + 1):
        row = list(map(int, input().split()))
        for x in range(1, m + 1):
            prefix[y][x] = (row[x - 1] 
                          + prefix[y - 1][x] 
                          + prefix[y][x - 1] 
                          - prefix[y - 1][x - 1])
    
    for _ in range(k):
        y1, x1, y2, x2 = map(int, input().split())
        
        result = (prefix[y2][x2] 
                - prefix[y1 - 1][x2] 
                - prefix[y2][x1 - 1] 
                + prefix[y1 - 1][x1 - 1])
        
        print(result)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n·m + k) | **Память:** O(n·m)
## Задача 3: Коровы в стойла

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Бинарный поиск по ответу + жадный алгоритм** |
| **Зачем** | Найти максимальное минимальное расстояние |
| **Почему** | Монотонность: если можно с расстоянием D, можно и с любым < D |
| **Ключевая идея** | Бинарно ищем ответ, жадно проверяем возможность |
| **Проверка** | Ставим корову в первое доступное стойло |

**Почему жадный работает:**
```
Ставя каждую корову в ПЕРВОЕ возможное стойло,
мы оставляем МАКСИМУМ места для остальных коров.

Жадное:  🐄_______🐄_______🐄__________
Другое:  ___🐄_______🐄_______🐄_______
         ↑
    "потеряли" место слева
```

### 💻 Код (Python)

```python
import sys

def can_place(stalls, k, min_dist):
    """Можно ли разместить k коров с мин. расстоянием min_dist"""
    cows = 1
    last = stalls[0]
    
    for i in range(1, len(stalls)):
        if stalls[i] - last >= min_dist:
            cows += 1
            last = stalls[i]
            if cows >= k:
                return True
    return False

def solve():
    input = sys.stdin.readline
    
    n, k = map(int, input().split())
    stalls = list(map(int, input().split()))
    
    left, right = 1, stalls[-1] - stalls[0]
    answer = 0
    
    while left <= right:
        mid = (left + right) // 2
        
        if can_place(stalls, k, mid):
            answer = mid
            left = mid + 1  # Пробуем больше
        else:
            right = mid - 1  # Нужно меньше
    
    print(answer)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n · log(max_dist)) | **Память:** O(n)
## Задача 4: Таблица умножения

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Бинарный поиск по ответу + подсчёт элементов** |
| **Зачем** | Найти k-е число без генерации всей таблицы |
| **Почему** | Таблица n² = 10¹⁰ элементов — нельзя хранить |
| **Ключевая идея** | Считаем сколько чисел ≤ X за O(n) |
| **Формула** | В строке i: min(n, X // i) чисел ≤ X |

**Почему это работает:**
```
Для строки i значения: i×1, i×2, i×3, ..., i×n
Сколько из них ≤ X?
    i × j ≤ X  →  j ≤ X / i
Но j ≤ n, поэтому: min(n, X // i)
```

### 💻 Код (Python)

```python
import sys

def count_less_equal(n, x):
    """Сколько чисел в таблице n×n не превосходят x"""
    count = 0
    for i in range(1, n + 1):
        count += min(n, x // i)
    return count

def solve():
    input = sys.stdin.readline
    
    n, k = map(int, input().split())
    
    left, right = 1, n * n
    answer = right
    
    while left <= right:
        mid = (left + right) // 2
        
        if count_less_equal(n, mid) >= k:
            answer = mid
            right = mid - 1  # Ищем меньше
        else:
            left = mid + 1  # Нужно больше
    
    print(answer)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n · log n) | **Память:** O(1)
## Задача 5: Разделение массива

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Бинарный поиск по ответу + жадная проверка** |
| **Зачем** | Минимизировать максимальную сумму отрезка |
| **Почему** | Классическая задача "minimize the maximum" |
| **Ключевая идея** | Бинарно ищем ответ, жадно проверяем разбиение |
| **Границы** | left = max(arr), right = sum(arr) |

**Почему жадная проверка работает:**
```
Идём слева направо, добавляем в текущий отрезок
пока сумма ≤ X. Когда не влезает → новый отрезок.

Это оптимально: откладываем разрыв как можно дальше,
оставляя больше элементов для будущих отрезков.
```

### 💻 Код (Python)

```python
import sys

def can_split(arr, k, max_sum):
    """Можно ли разбить на ≤ k отрезков с макс. суммой ≤ max_sum"""
    segments = 1
    current = 0
    
    for x in arr:
        if x > max_sum:
            return False
        if current + x > max_sum:
            segments += 1
            current = x
        else:
            current += x
    
    return segments <= k

def solve():
    input = sys.stdin.readline
    
    n, k = map(int, input().split())
    arr = list(map(int, input().split()))
    
    left, right = max(arr), sum(arr)
    answer = right
    
    while left <= right:
        mid = (left + right) // 2
        
        if can_split(arr, k, mid):
            answer = mid
            right = mid - 1  # Пробуем меньше
        else:
            left = mid + 1  # Нужно больше
    
    print(answer)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n · log(sum)) | **Память:** O(n)
## Задача 6: Закраска прямой

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Сортировка + слияние пересекающихся отрезков** |
| **Зачем** | Найти длину объединения отрезков |
| **Почему** | Отрезки могут пересекаться — нельзя просто сложить длины |
| **Ключевая идея** | Сортируем по левому концу, объединяем пересекающиеся |
| **Условие** | Отрезки пересекаются если next_left ≤ current_right |

**Почему сортировка необходима:**
```
Без сортировки: [1,5], [10,15], [2,8] → сложно определить пересечения
После сортировки: [1,5], [2,8], [10,15] → линейный проход работает!

[1,5] и [2,8]: 2 ≤ 5 ✅ → объединяем в [1,8]
[1,8] и [10,15]: 10 ≤ 8 ❌ → новый отрезок
```

### 💻 Код (Python)

```python
import sys

def solve():
    input = sys.stdin.readline
    
    n = int(input())
    segments = []
    
    for _ in range(n):
        l, r = map(int, input().split())
        segments.append((l, r))
    
    segments.sort(key=lambda x: x[0])  # Сортировка по левому концу
    
    total = 0
    if n == 0:
        print(0)
        return
    
    cur_l, cur_r = segments[0]
    
    for i in range(1, n):
        next_l, next_r = segments[i]
        
        if next_l <= cur_r:  # Пересекаются
            cur_r = max(cur_r, next_r)
        else:  # Не пересекаются
            total += cur_r - cur_l
            cur_l, cur_r = next_l, next_r
    
    total += cur_r - cur_l  # Последний отрезок
    print(total)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n log n) | **Память:** O(n)
## Задача 7: Кассы

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Sweep Line (метод сканирующей прямой)** |
| **Зачем** | Найти время, когда все кассы работают одновременно |
| **Почему** | Нужно отслеживать изменение количества активных касс |
| **Ключевая идея** | Создаём события (+1 открытие, -1 закрытие), сортируем |
| **Особенности** | 3 типа интервалов: обычный, через полночь, круглосуточно |

**Почему Sweep Line работает:**
```
Время:    00:00    06:00    12:00    18:00    24:00
          |--------|--------|--------|--------|
Касса 1:      [████████████████████]            (06:00-22:00)
Касса 2:  [████████████]                        (00:00-12:00)
Касса 3:                    [████████████████]  (12:00-20:00)

События: +1 в 06:00, +1 в 00:00, -1 в 22:00, -1 в 12:00, +1 в 12:00, -1 в 20:00
Считаем active_count между событиями
```

### 💻 Код (Python)

```python
import sys

def to_seconds(h, m, s):
    return h * 3600 + m * 60 + s

def solve():
    input = sys.stdin.readline
    
    n = int(input())
    events = []
    always_open = 0
    
    for _ in range(n):
        h1, m1, s1, h2, m2, s2 = map(int, input().split())
        open_t = to_seconds(h1, m1, s1)
        close_t = to_seconds(h2, m2, s2)
        
        if open_t == close_t:  # Круглосуточно
            always_open += 1
        elif open_t < close_t:  # Обычный интервал
            events.append((open_t, 1))
            events.append((close_t, -1))
        else:  # Через полночь
            events.append((open_t, 1))
            events.append((86400, -1))
            events.append((0, 1))
            events.append((close_t, -1))
    
    need = n - always_open
    
    if need == 0:
        print(86400)
        return
    
    events.sort()
    
    total = 0
    active = 0
    last = 0
    
    for time, delta in events:
        if active == need:
            total += time - last
        active += delta
        last = time
    
    print(total)

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n log n) | **Память:** O(n)
## Задача 8: Межрегиональная олимпиада

### 📖 Теоретическая справка

| Аспект | Описание |
|--------|----------|
| **Техника** | **Динамическое программирование + бинарный поиск** |
| **Зачем** | Максимизировать количество решённых задач |
| **Почему не жадный** | Задачу можно начать ТОЛЬКО в момент sᵢ, не позже! |
| **Ключевая идея** | dp[i] = макс. задач с i-й до конца |
| **Переход** | skip: dp[i+1] или take: 1 + dp[first_after_end] |

**Почему жадный НЕ работает:**
```
Задача 1: s=1, t=10 → [1, 11]
Задача 2: s=2, t=1  → [2, 3]
Задача 3: s=3, t=1  → [3, 4]

Жадный (по окончанию): берёт Задачу 1 → 1 задача ❌
Оптимально: пропускаем 1, берём 2 и 3 → 2 задачи ✅
```

**Почему DP работает:**
```
dp[i] = максимум задач, рассматривая задачи с i до n-1

Для задачи i:
1. Пропустить: dp[i+1]
2. Взять: 1 + dp[j], где j — первая задача со start ≥ end_i

Выбираем максимум из двух вариантов
```

### 💻 Код (Python)

```python
import sys
from bisect import bisect_left

def solve():
    input = sys.stdin.readline
    
    n, c = map(int, input().split())
    
    tasks = []
    for i in range(n):
        s, t = map(int, input().split())
        tasks.append((s, t, i + 1))
    
    tasks.sort(key=lambda x: x[0])  # Сортировка по времени старта
    start_times = [tasks[i][0] for i in range(n)]
    
    # DP справа налево
    dp = [0] * (n + 1)
    take = [False] * n
    
    for i in range(n - 1, -1, -1):
        s, t, idx = tasks[i]
        end_time = s + t
        
        skip_val = dp[i + 1]
        j = bisect_left(start_times, end_time)
        take_val = 1 + dp[j]
        
        if take_val > skip_val:
            dp[i] = take_val
            take[i] = True
        else:
            dp[i] = skip_val
            take[i] = False
    
    # Восстановление ответа
    selected = []
    i = 0
    while i < n:
        if take[i]:
            selected.append(tasks[i][2])
            end_time = tasks[i][0] + tasks[i][1]
            i = bisect_left(start_times, end_time)
        else:
            i += 1
    
    print(len(selected) * c)
    print(len(selected))
    print(' '.join(map(str, selected)))

if __name__ == "__main__":
    solve()
```

**Сложность:** O(n log n) | **Память:** O(n)

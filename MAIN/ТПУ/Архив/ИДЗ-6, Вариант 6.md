## 1. Изменение энергетической светимости

**Дано:** $T_0 = 1000\ К$, половина поверхности: $T_1 = 1100\ К$, $T_2 = 900\ К$. Тело — абсолютно чёрное.

**Решение:**
По закону Стефана-Больцмана: $R = \sigma T^4$

$$\frac{R}{R_0} = \frac{0{,}5\sigma T_1^4 + 0{,}5\sigma T_2^4}{\sigma T_0^4} = 0{,}5\left[\left(\frac{1100}{1000}\right)^4 + \left(\frac{900}{1000}\right)^4\right]$$

$$= 0{,}5\left[1{,}1^4 + 0{,}9^4\right] = 0{,}5\left[1{,}4641 + 0{,}6561\right] = 1{,}0601$$

**Ответ:** Энергетическая светимость увеличится в **1,06 раза** (на ~6%).

## 2. Температура после остывания чёрного тела

**Дано:** $T_1 = 1900\ К$, $\Delta\lambda_{max} = 9\ мкм = 9\cdot10^{-6}\ м$.

**Решение:**
По закону смещения Вина: $\lambda_{max} \cdot T = b$, где $b = 2{,}898\cdot10^{-3}\ м\cdotК$

$$\lambda_1 = \frac{b}{T_1} = \frac{2{,}898\cdot10^{-3}}{1900} = 1{,}525\cdot10^{-6}\ м$$

При остывании $\lambda_{max}$ растёт: $\lambda_2 = \lambda_1 + \Delta\lambda = 10{,}525\cdot10^{-6}\ м$

$$T_2 = \frac{b}{\lambda_2} = \frac{2{,}898\cdot10^{-3}}{10{,}525\cdot10^{-6}} \approx 275\ К$$

**Ответ:** $T_2 \approx \boxed{275\ К}$

## 3. Длина волны максимума излучения при взрыве бомбы

**Дано:** $T \approx 10^7\ К$.

**Решение:**
$$\lambda_{max} = \frac{b}{T} = \frac{2{,}898\cdot10^{-3}}{10^7} = 2{,}898\cdot10^{-10}\ м = 0{,}29\ нм$$

**Ответ:** $\lambda_{max} \approx \boxed{0{,}29\ нм}$ (рентгеновский диапазон)

## 4. Задерживающий потенциал для калия

**Дано:** $A = 2{,}0\ эВ$, $\lambda = 330\ нм$.

**Решение:**
Уравнение Эйнштейна: $eU_з = \dfrac{hc}{\lambda} - A$

$$\frac{hc}{\lambda} = \frac{1240\ эВ\cdotнм}{330\ нм} \approx 3{,}76\ эВ$$

$$U_з = \frac{3{,}76 - 2{,}0}{1} = 1{,}76\ В$$

**Ответ:** $U_з \approx \boxed{1{,}76\ В}$

## 5. Комптон-эффект: изменение длины волны

**Дано:** $\lambda = 0{,}0712\ нм$, $\theta = 90^\circ$.

**Решение:**
Формула Комптона: $\Delta\lambda = \dfrac{h}{m_0c}(1 - \cos\theta)$

При $\theta = 90^\circ$: $\Delta\lambda = \dfrac{h}{m_0c} = \lambda_C$ (комптоновская длина волны)

1) **Для электрона:** $\lambda_{C,e} = 2{,}43\ пм = \boxed{2{,}43\cdot10^{-12}\ м}$

2) **Для атома углерода** ($m_C \approx 12\cdot1836\cdot m_e$):
$$\Delta\lambda_C = \lambda_{C,e} \cdot \frac{m_e}{m_C} = 2{,}43\ пм \cdot \frac{1}{22032} \approx \boxed{1{,}1\cdot10^{-4}\ пм}$$

## 6. Масса частицы по длине волны де Бройля

**Дано:** $U = 200\ В$, $\lambda = 2{,}2\ пм$, $q = e$.

**Решение:**
$$\lambda = \frac{h}{p} = \frac{h}{\sqrt{2mE_k}} = \frac{h}{\sqrt{2meU}}$$

$$m = \frac{h^2}{2eU\lambda^2} = \frac{(6{,}626\cdot10^{-34})^2}{2\cdot1{,}6\cdot10^{-19}\cdot200\cdot(2{,}2\cdot10^{-12})^2} \approx 2{,}84\cdot10^{-30}\ кг$$

$$\frac{m}{m_e} = \frac{2{,}84\cdot10^{-30}}{9{,}11\cdot10^{-31}} \approx 3{,}12$$

**Ответ:** $m \approx \boxed{3{,}12\ m_e}$ (частица тяжелее электрона ~в 3 раза)

## 7. Кинетическая энергия электрона в атоме водорода

**Решение:**
Для водорода: $E_n = -\dfrac{13{,}6}{n^2}\ эВ$, $K_n = |E_n|$

$$n=1:\ K_1 = 13{,}6\ эВ$$
$$n=2:\ K_2 = \frac{13{,}6}{4} = 3{,}4\ эВ$$
$$n=\infty:\ K_\infty = 0\ эВ$$

**Ответ:** $\boxed{13{,}6\ эВ;\ 3{,}4\ эВ;\ 0\ эВ}$

## 8. Три спектральные линии водорода

**Решение:**
Для наблюдения 3 линий нужно возбуждение до $n=3$ (переходы: $3\to2$, $3\to1$, $2\to1$).

**Границы длин волн возбуждающего света:**
- Минимум: переход $1\to3$: $\dfrac{1}{\lambda_{min}} = R\left(1 - \dfrac{1}{9}\right) \Rightarrow \lambda_{min} = 102{,}6\ нм$
- Максимум: переход $2\to3$: $\dfrac{1}{\lambda_{max}} = R\left(\dfrac{1}{4} - \dfrac{1}{9}\right) \Rightarrow \lambda_{max} = 656{,}3\ нм$

**Длины волн излучаемых линий:**
- $2\to1$ (Лайман-α): $\lambda = 121{,}6\ нм$
- $3\to1$ (Лайман-β): $\lambda = 102{,}6\ нм$
- $3\to2$ (Бальмер-α): $\lambda = 656{,}3\ нм$

**Ответ:** 
- Диапазон возбуждения: $\boxed{102{,}6\ нм \leq \lambda \leq 656{,}3\ нм}$
- Линии излучения: $\boxed{102{,}6\ нм;\ 121{,}6\ нм;\ 656{,}3\ нм}$

## 9. Разность первых потенциалов возбуждения He⁺ и H

**Решение:**
Для водородоподобных атомов: $\Delta E_{1\to2} = 13{,}6\cdot Z^2\left(1 - \dfrac{1}{4}\right) = 10{,}2\cdot Z^2\ эВ$

- Водород ($Z=1$): $\Delta E_H = 10{,}2\ эВ$
- Гелий ионизированный ($Z=2$): $\Delta E_{He} = 10{,}2\cdot4 = 40{,}8\ эВ$

$$\Delta U = \frac{\Delta E_{He} - \Delta E_H}{e} = 30{,}6\ В$$

**Ответ:** Разность потенциалов $\boxed{30{,}6\ В}$

## 10. Отношение вероятностей в потенциальном ящике

**Дано:** Ящик шириной $L$, интервал $0 < x < L/27$, состояния $n_1=3$ (второе возбуждённое), $n_2=5$ (четвёртое возбуждённое).

**Решение:**
$$\psi_n(x) = \sqrt{\frac{2}{L}}\sin\frac{n\pi x}{L}, \quad P_n = \int_0^{L/27} |\psi_n|^2 dx$$

Для малого интервала $\sin^2\alpha \approx \alpha^2$:
$$P_n \approx \frac{2}{L} \int_0^{L/27} \left(\frac{n\pi x}{L}\right)^2 dx = \frac{2n^2\pi^2}{3L^3} \cdot \left(\frac{L}{27}\right)^3 = \frac{2\pi^2 n^2}{3\cdot27^3}$$

$$\frac{P_{n=3}}{P_{n=5}} = \left(\frac{3}{5}\right)^2 = \frac{9}{25} = 0{,}36$$

**Ответ:** $\boxed{0{,}36}$

## 11. Температура для квазинепрерывного спектра

**Дано:** $L = 10^{-8}\ см = 10^{-10}\ м$.

**Решение:**
Уровни энергии: $E_n = \dfrac{n^2h^2}{8mL^2}$

Минимальный интервал (между $n=1$ и $n=2$):
$$\Delta E_{min} = E_2 - E_1 = \frac{3h^2}{8mL^2} = \frac{3\cdot(6{,}626\cdot10^{-34})^2}{8\cdot9{,}11\cdot10^{-31}\cdot10^{-20}} \approx 1{,}8\cdot10^{-17}\ Дж \approx 112\ эВ$$

Условие непрерывности: $kT \gg \Delta E_{min}$

$$T \gg \frac{112\ эВ}{k} = \frac{112\cdot1{,}6\cdot10^{-19}}{1{,}38\cdot10^{-23}} \approx \boxed{1{,}3\cdot10^6\ К}$$

## 13. Снижение активности $^{192}_{77}Ir$ за 30 суток

**Дано:** $t = 30\ сут$, $T_{1/2}(^{192}Ir) = 73{,}8\ сут$.

**Решение:**
$$\lambda = \frac{\ln 2}{T_{1/2}} = \frac{0{,}693}{73{,}8} = 9{,}39\cdot10^{-3}\ сут^{-1}$$

$$\frac{A}{A_0} = e^{-\lambda t} = e^{-9{,}39\cdot10^{-3}\cdot30} = e^{-0{,}282} \approx 0{,}754$$

Снижение: $1 - 0{,}754 = 0{,}246 = 24{,}6\%$

**Ответ:** Активность снизится на $\boxed{24{,}6\%}$

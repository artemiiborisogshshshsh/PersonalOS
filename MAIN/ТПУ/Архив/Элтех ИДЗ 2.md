### **2.2 Система уравнений в дифференциальной форме**

**По первому закону Кирхгофа (узлы):**

**Узел a:**
```
-i₁(t) - j(t) - i_ad(t) = 0
```

**Узел b:**
```
i₁(t) - i_bd(t) - i_bc(t) = 0
```

**Узел d:**
```
i_ad(t) + i_bd(t) - i_dc(t) = 0
```

**По второму закону Кирхгофа (контуры):**

**Контур 1 (a-b-d-a):**
```
u_bd(t) - u_ad(t) = e₁(t)

где:
u_ad(t) = i_ad(t)·(R/2) + L·di_ad(t)/dt - M·di_dc(t)/dt
u_bd(t) = i_bd(t)·R_bd + (1/C)·∫i_bd(t)dt
```

**Контур 2 (b-c-d-b):**
```
u_bc(t) - u_dc(t) - u_bd(t) = -e₂(t)

где:
u_bc(t) = i_bc(t)·2R
u_dc(t) = -e₂(t) + i_dc(t)·R + L·di_dc(t)/dt - M·di_ad(t)/dt
```

**Знак перед M:** встречное включение катушек (один ток втекает, другой вытекает из одноимённых зажимов) → знак **минус**.

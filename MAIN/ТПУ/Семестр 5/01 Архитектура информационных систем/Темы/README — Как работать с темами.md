# Как работать с темами

## Иерархия материалов

| Уровень | Назначение | Примеры |
|---|---|---|
| **Лекция** | Материал занятия (конспект) | Лекция 01 — Введение в архитектуру ИС |
| **Практика** | Применение теории на занятии | Практика 01 — Анализ архитектурных стилей |
| **Лабораторная** | Выполнение практической работы | Лабораторная 01 — Моделирование системы |
| **Тема** | Самостоятельная единица знания для повторения | Процессы, Потоки, Транзакции, Архитектурные стили |

## Когда создавать тему

1. После лекции/практики/лабы — выдели ключевую концепцию, которую нужно запомнить
2. Если тема повторяется в нескольких занятиях — создай одну заметку-тему
3. Для подготовки к экзамену/зачёту — каждая тема = один вопрос билета

## Metadata темы

```yaml
type: topic
semester: 5
discipline: "Название дисциплины"
status: not_started | in_progress | completed
difficulty: 1-5
review:
  last_review: 2026-09-15
  next_review: 2026-09-16
  interval: 1
tags:
  - semester-5
  - topic
```

## Интервальное повторение

| Повторение | Интервал | Когда следущее |
|---|---|---|
| 1-е | 1 день | `next_review = last_review + 1` |
| 2-е | 3 дня | `+3` |
| 3-е | 7 дней | `+7` |
| 4-е | 14 дней | `+14` |
| 5-е | 30 дней | `+30` |

После каждого успешного повторения:
1. `last_review = today`
2. `interval = следующий интервал из таблицы`
3. `next_review = today + interval`

## Связи

- В теме ссылайся на лекции/практики/лабы: `[[Лекция 01 — ...]]`
- В лекциях/практиках/лабах ссылайся на темы: `[[Темы/Процессы]]`
- Используй Dataview для авто-сборки списка тем по дисциплине

## 📊 Прогресс

```dataview
TABLE 
  length(filter(rows, (r) => r.status = "completed")) + "/" + length(rows) AS "Выполнено/Всего",
  round((length(filter(rows, (r) => r.status = "completed")) / length(rows)) * 100) + "%" AS "Прогресс"
FROM ""
WHERE type IN ["lecture", "practice", "laboratory", "self-study", "control"]
  AND discipline = this.file.name
GROUP BY true
```

## 📅 Ближайшие дедлайны

```dataview
TABLE 
  work_type AS "Тип",
  number AS "№",
  due AS "Дедлайн",
  status AS "Статус",
  date(due) - date(today) AS "Дней"
FROM ""
WHERE type = "deadline"
  AND discipline = this.file.name
  AND due >= date(today)
  AND status != "completed"
SORT due ASC
LIMIT 10
```

## ⚠️ Требует внимания

```dataview
TABLE
  work_type AS "Тип",
  number AS "№",
  status AS "Статус",
  due AS "Дедлайн",
  difficulty AS "Сложность"
FROM ""
WHERE discipline = this.file.name
  AND type IN ["lecture", "practice", "laboratory", "self-study", "control"]
  AND (status = "overdue" OR status = "not_started" AND due < date(today) OR difficulty >= 4 AND status != "completed")
SORT difficulty DESC, due ASC
```

# 1️⃣ СЛОВАРИ (`dict`)

## Что такое словарь простыми словами

**Словарь = ящик с подписями**

`ключ → значение`

Пример из жизни:

`"имя" → "Алексей" "возраст" → 18`

## Как выглядит словарь в Python

`user = {     "level": 1,     "xp": 0,     "state": "intro" }`

### Что тут что

- `"level"` — ключ
    
- `1` — значение
    
- ключи **уникальны**
    
- значения могут быть **любыми**
    

---

## Как получить значение

`user["level"]      # 1 user["state"]      # "intro"`

---

## Как изменить значение

`user["xp"] += 10 user["state"] = "question_2"`

---

## Как словари используются в игре

### Словарь всех пользователей

`users = {     123456789: {         "level": 1,         "xp": 20,         "state": "question_1"     } }`

### Что это значит

`users[user_id]["state"]`

↓

> «дай состояние конкретного игрока»

---

## Почему словари — основа бота

- легко хранить данные
    
- быстро получать доступ
    
- идеально для состояний
    
- проще, чем классы на старте

# 2️⃣ ДЕКОРАТОРЫ (`@`)

## Самое простое объяснение

**Декоратор = “когда произошло Х → вызови эту функцию”**

---

## Пример из бота

`@bot.message_handler(commands=['start']) def start(message):     ...`

### Читаем по-человечески

> «Если пользователь написал `/start`,  
> вызови функцию `start`  
> и передай ей сообщение»

---

## Что делает `@bot.message_handler`

- регистрирует функцию
    
- Telegram знает, **когда её вызывать**
    
- сам ты её **не вызываешь**
    

Ты НЕ пишешь:

`start(message)`

Telegram делает это **за тебя**.

---

## Другой пример — ловим ВСЕ сообщения

`@bot.message_handler(func=lambda message: True) def handle_game(message):     ...`

### Перевод

> «Любое сообщение → сюда»

А дальше ты сам решаешь:

`if user["state"] == "question_1":     ...`

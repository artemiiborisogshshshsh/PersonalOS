## **Блок 2. Рекурсия**

### Тест
1. **б)** — `4+3+2+1+0 = 10`

### Задания
```python
# 7
def sum_digits(n):
    if n < 10:
        return n
    return n % 10 + sum_digits(n // 10)

# 8
def replace_char(s, old, new):
    if not s:
        return ""
    head = new if s[0] == old else s[0]
    return head + replace_char(s[1:], old, new)

# 9
def is_palindrome(s):
    if len(s) <= 1:
        return True
    if s[0] != s[-1]:
        return False
    return is_palindrome(s[1:-1])

# 10 ⭐
def count_occurrences(lst, x):
    if not lst:
        return 0
    return (1 if lst[0] == x else 0) + count_occurrences(lst[1:], x)
```

## **Блок 3. Lambda, map, filter**

### Тест
1. **б)** — фильтр оставляет чётные: `[2, 4]`

### Задания
```python
# 11
def squares(nums):
    return list(map(lambda x: x ** 2, nums))

# 12
def capitalized_only(words):
    return list(filter(lambda w: w and w[0].isupper(), words))

# 13
def format_numbers(nums):
    return list(map(lambda x: f"число = {x}", nums))

# 14 ⭐
def positive_cubes(nums):
    return list(map(lambda x: x ** 3, filter(lambda x: x > 0, nums)))
```

## **Блок 4. Свободный выбор подхода**

```python
# 15
def join_with_dash(words):
    return "-".join(words)

# 16
def count_negatives(lst):
    return sum(1 for x in lst if x < 0)

# 17
def remove_punctuation(text):
    return ''.join(ch for ch in text if ch.isalnum() or ch.isspace())

# 18 ⭐
def alternating_sum(lst):
    return sum(x if i % 2 == 0 else -x for i, x in enumerate(lst))
```

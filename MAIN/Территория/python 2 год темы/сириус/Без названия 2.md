## 1. Теоретический материал

### 1.1. Понятие алгоритма и исполнителя
**[[алгоритм]]** — это последовательность команд для исполнителя, приводящая к заранее поставленной цели.

**Свойства [[алгоритм]]а:**
- **Дискретность:** Разбиение на отдельные шаги (команды).
- **Понятность:** Команды должны входить в систему команд исполнителя (СКИ).
- **Определённость:** Каждая команда должна быть понятна однозначно.
- **Конечность:** Алгоритм должен завершаться за конечное число шагов.
- **Массовость:** Применимость к однотипным задачам.

**Исполнитель [[алгоритм]]а:**
Объект (человек, устройство, компьютер), способный выполнять команды алгоритма.

**Примеры учебных исполнителей (из Практикума):**
- **Водолей:** Работает с сосудами, команды: `наполнить`, `вылить`, `перелить`.
- **Чертежник:** Перемещает перо по координатной плоскости, команды: `сместиться на вектор`, `опустить перо`.
- **Робот:** Двигается по клетчатому полю, команды: `вверх`, `вниз`, `закрасить`, условия: `сверху стена`, `клетка закрашена`.
- **Черепаха:** Рисует фигуры, команды: `вперед`, `назад`, `вправо`, `влево`.

**Формальное исполнение:**
Исполнитель выполняет команды механически, не вникая в смысл задачи. Ошибка возникает, если команда не входит в СКИ или нарушает среду (например, Робот идет в стену).

### 1.2. Основные алгоритмические конструкции

**1. Линейная:**
Команды выполняются последовательно, одна за другой, без ветвлений и повторений.

**2. Ветвление:**
Выбор пути выполнения алгоритма в зависимости от условия.
- **Полное:** `если условие то ... иначе ...`.
- **Неполное:** `если условие то ...`
- *В языке Pascal:* `if ... then ... else ...`
- *В языке [[Python]]:* `if ... : ... else : ...`

**3. Выбор (множественное ветвление):**
Выбор одного из нескольких вариантов (в учебниках реализуется через последовательные `если` или `case` в Pascal).

**4. Цикл:**
Многократное выполнение однотипных действий.
- **Цикл с параметром (счетчиком):** `нц для i от 1 до n` (Алг. язык), `for i in range(...)` ([[Python]]), `for i := 1 to n do` (Pascal).
- **Цикл с условием:** `нц пока условие` (Алг. язык), `while условие:` ([[Python]]).
### 1.3. Использование переменных

**[[переменная]]:**
Именованная ячейка памяти, значение которой может изменяться в ходе выполнения алгоритма.

**Объявление переменной:**
- **Имя:** Уникальное обозначение (например, `x`, `sum`, `a1`).
- **Тип:** Определяет множество допустимых значений и операции.
- **Значение:** Конкретные данные, хранящиеся в переменной.

**Типы данных (на основе учебников):**
1. **Целый (`integer` / `цел`):** Целые числа.
2. **Вещественный (`real` / `вещ`):** Дробные числа.
3. **Символьный/Строковый (`string` / `лит`):** Последовательность символов
4. **Логический (`boolean` / `лог`):** Принимает значения `TRUE`/`FALSE` (Истина/Ложь)
5. **Массив (Табличный тип):** Упорядоченный набор элементов одного типа, доступ по индексу

**Объявление в языках программирования:**
- **Pascal:** `var x: integer;` (в разделе описания)
- **[[Python]]:** Переменные не объявляются явно, тип определяется значением: `x = 5`
- **Алгоритмический язык:** `цел x` (в начале алгоритма)

### 1.4. Чтение и написание программ

**Чтение программы:**
Требует понимания синтаксиса языка и логики алгоритма.
*Пример на [[Python]]:*
```python
s = 0
for i in range(1, 11):
    s = s + i
print(s)
```
*Анализ:* Цикл от 1 до 10, сумма чисел. Результат: 55.

**Написание программы:**
Включает этапы: постановка задачи, формализация, алгоритмизация, программирование, отладка
*Использование функций:* Встроенные (`print`, `input`, `sqrt`) и пользовательские (процедуры и функции в Pascal)
### 1.5. Описание реального объекта и процесса

**Моделирование:**
Замена реального объекта его моделью для изучения
**Описание процесса управления:**
Включает управляющий объект, управляемый объект и каналы связи (прямая и обратная связь)
*Пример:* Управление движением автомобиля (светорегулятор — объект управления, автомобиль — управляемый объект
**Алгоритмическое описание:**
Процесс описывается через последовательность действий над данными объекта (например, алгоритм покраски клеток Роботом описывает процесс обработки поля)

## 2. Примеры разбора задач

### Пример 1. Трассировка переменных (Чтение кода)
**Условие:** Определите значение переменной `s` после выполнения программы:
```python
s = 0
for i in range(1, 6):
    s = s + i
```
**Решение:**
1. `i=1`, `s = 0 + 1 = 1`
2. `i=2`, `s = 1 + 2 = 3`
3. `i=3`, `s = 3 + 3 = 6`
4. `i=4`, `s = 6 + 4 = 10`
5. `i=5`, `s = 10 + 5 = 15`
**Ответ:** 15
### Пример 2. Исполнитель Робот (Ветвление и Цикл)
**Условие:** Робот находится в клетке. Напишите алгоритм, чтобы он закрасил все клетки коридора слева и справа от себя и вернулся в исходную точку.
**Решение (Алгоритмический язык):**
```alg
нц пока слева свободно
    влево
    закрасить
кц
нц пока справа свободно
    вправо
    закрасить
кц
```
*(Примечание: для возврата нужны дополнительные команды, в зависимости от условия)*
### Пример 3. Описание процесса (Формализация)
**Условие:** Автомобиль тормозит с ускорением -5 м/с². Найти путь до остановки.
**Решение:**
1. **Дано:** `v0` (нач. скорость), `a = -5`, `v = 0` (кон. скорость).
2. **Найти:** `s`.
3. **Формула:** `s = (v² - v0²) / (2 * a)` → `s = -v0² / (2 * a)`
4. **Программа (Pascal):**
```pascal
var v0, s: real;
begin
  readln(v0);
  s := -sqr(v0) / (2 * -5);
  writeln(s);
end.
```

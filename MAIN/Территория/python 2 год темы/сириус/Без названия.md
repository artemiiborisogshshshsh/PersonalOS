# ДИДАКТИЧЕСКИЕ МАТЕРИАЛЫ ПО ТЕМЕ:
# ЧАСТЬ 1: ТЕОРЕТИЧЕСКИЙ МАТЕРИАЛ

## 1.1. Единицы измерения количества информации

**Основная единица — бит:**
- **1 бит** — минимальная единица информации (может принимать значение 0 или 1)
- **1 байт** = 8 бит = 2³ бит
- **1 Кбайт** = 1024 байт = 2¹⁰ байт
- **1 Мбайт** = 1024 Кбайт = 2²⁰ байт
- **1 Гбайт** = 1024 Мбайт = 2³⁰ байт


## 1.2. Формулы для расчёта информационного объёма

### Формула Хартли (для равновероятных событий):
$$N = 2^i$$
где:
- $N$ — количество возможных равновероятных событий (мощность алфавита)
- $i$ — количество бит информации для кодирования одного события



### Формула информационного объёма сообщения:
$$I = K \times i$$
где:
- $I$ — общий информационный объём сообщения
- $K$ — количество символов/элементов в сообщении
- $i$ — информационный вес одного символа/элемента (в битах)



### Формула для передачи данных:
$$I = v \times t$$
где:
- $I$ — объём переданной информации
- $v$ — скорость передачи данных (бит/с, Кбит/с, Мбит/с)
- $t$ — время передачи (секунды)






## 1.3. Информационный объём текста

**Кодирование символов:**
- **ASCII** — 1 символ = 1 байт = 8 бит (256 символов)
- **Unicode (UTF-16)** — 1 символ = 2 байта = 16 бит (65536 символов)
- **Unicode (UTF-8)** — 1 символ = 1-4 байта (в зависимости от символа)

**Формула:**
$$I_{текст} = K_{символов} \times i_{символа}$$





## 1.4. Информационный объём графического изображения

**Для растрового изображения:**
$$I_{изобр} = K_{пикселей} \times i_{цвета}$$

где:
- $K_{пикселей} = ширина \times высота$ (в пикселях)
- $i_{цвета}$ — глубина цвета (бит на пиксель)

**Глубина цвета:**
- Чёрно-белое: 1 бит (2 цвета)
- 16 цветов: 4 бита
- 256 цветов: 8 бит (1 байт)
- High Color (65536 цветов): 16 бит (2 байта)
- True Color (16,7 млн цветов): 24 бита (3 байта)





## 1.5. Информационный объём звукового файла

**Формула:**
$$I_{аудио} = v_{дискрет} \times i_{разреш} \times K_{каналов} \times t$$

где:
- $v_{дискрет}$ — частота дискретизации (Гц, кГц)
- $i_{разреш}$ — глубина кодирования (бит)
- $K_{каналов}$ — количество каналов (1 — моно, 2 — стерео)
- $t$ — время звучания (секунды)



**Типичные параметры:**
| Параметр | Значение |

| Параметр              | Значение                        |
| --------------------- | ------------------------------- |
| Частота дискретизации | 8 кГц, 16 кГц, 44,1 кГц, 48 кГц |
| Глубина кодирования   | 8 бит, 16 бит, 24 бит           |
| Количество каналов    | 1 (моно), 2 (стерео)            |


## 1.6. Информационный объём видеофайла

**Формула:**
$$I_{видео} = I_{кадр} \times K_{кадров} \times t + I_{аудио}$$

или

$$I_{видео} = (ширина \times высота \times i_{цвета} \times FPS) \times t + I_{аудио}$$

где:
- $FPS$ — количество кадров в секунду (frames per second)
- $t$ — длительность видео (секунды)
- $I_{аудио}$ — объём звуковой дорожки



**Типичные параметры:**

| Параметр | Значение |
|----------|----------|
| Разрешение | 640×480, 1280×720, 1920×1080 |
| FPS | 24, 25, 30, 60 кадров/с |
| Глубина цвета | 24 бита (True Color) |



# ЧАСТЬ 2: ПРИМЕРЫ РАЗБОРА ЗАДАЧ

## Пример 1. Текст
**Условие:** Статья содержит 16 страниц, на каждой странице 32 строки, в каждой строке 40 символов. Каждый символ кодируется 16 битами (Unicode). Определите информационный объём статьи в Кбайтах.

**Решение:**
1. Общее количество символов: $K = 16 \times 32 \times 40 = 20\,480$ символов
2. Информационный объём в битах: $I = 20\,480 \times 16 = 327\,680$ бит
3. В байтах: $327\,680 / 8 = 40\,960$ байт
4. В Кбайтах: $40\,960 / 1024 = 40$ Кбайт

**Ответ:** 40 Кбайт




## Пример 2. Изображение
**Условие:** Расторовое изображение имеет размер 1024×768 пикселей. Глубина цвета — 24 бита. Определите информационный объём изображения в Мбайтах.

**Решение:**
1. Количество пикселей: $K = 1024 \times 768 = 786\,432$ пикселя
2. Объём в битах: $I = 786\,432 \times 24 = 18\,874\,368$ бит
3. В байтах: $18\,874\,368 / 8 = 2\,359\,296$ байт
4. В Кбайтах: $2\,359\,296 / 1024 = 2\,304$ Кбайт
5. В Мбайтах: $2\,304 / 1024 = 2,25$ Мбайт

**Ответ:** 2,25 Мбайт





## Пример 3. Аудиофайл
**Условие:** Определите объём стереоаудиофайла длительностью 1 минута, если частота дискретизации 44,1 кГц, глубина кодирования 16 бит.

**Решение:**
1. Частота дискретизации: $v = 44\,100$ Гц
2. Глубина кодирования: $i = 16$ бит
3. Количество каналов: $K = 2$ (стерео)
4. Время: $t = 60$ секунд
5. Объём в битах: $I = 44\,100 \times 16 \times 2 \times 60 = 84\,672\,000$ бит
6. В байтах: $84\,672\,000 / 8 = 10\,584\,000$ байт
7. В Мбайтах: $10\,584\,000 / 1024 / 1024 \approx 10,09$ Мбайт

**Ответ:** ≈10,09 Мбайт



 

## Пример 4. Видеофайл
**Условие:** Определите объём видеофайла длительностью 30 секунд с разрешением 1280×720, глубиной цвета 24 бита, 30 кадров в секунду (без звука).

**Решение:**
1. Количество пикселей в кадре: $1280 \times 720 = 921\,600$ пикселей
2. Объём одного кадра в битах: $921\,600 \times 24 = 22\,118\,400$ бит
3. Количество кадров: $30 \times 30 = 900$ кадров
4. Общий объём в битах: $22\,118\,400 \times 900 = 19\,906\,560\,000$ бит
5. В байтах: $19\,906\,560\,000 / 8 = 2\,488\,320\,000$ байт
6. В Мбайтах: $2\,488\,320\,000 / 1024 / 1024 \approx 2\,373$ Мбайт
7. В Гбайтах: $2\,373 / 1024 \approx 2,32$ Гбайт

**Ответ:** ≈2,32 Гбайт



 

## Пример 5. Передача данных
**Условие:** Скорость передачи данных через ADSL-соединение равна 128 000 бит/с. Какое время потребуется для передачи файла размером 625 Кбайт?

**Решение:**
1. Размер файла в битах: $I = 625 \times 1024 \times 8 = 5\,120\,000$ бит
2. Скорость: $v = 128\,000$ бит/с
3. Время: $t = I / v = 5\,120\,000 / 128\,000 = 40$ секунд

**Ответ:** 40 секунд

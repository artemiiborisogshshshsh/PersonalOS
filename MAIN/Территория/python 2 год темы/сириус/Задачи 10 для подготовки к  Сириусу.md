**13. Дружелюбные числа**



```Python
def sum_div(n):
    s = 1
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            if i * i == n: s += i
            else: s += i + n // i
    return s

a, b = int(input()), int(input())
print("YES" if sum_div(a) == b and sum_div(b) == a else "NO")
```

### Блок 4: Сложная логика

**16. Максимальное расстояние (подряд равные)**



```Python
count = 1
max_dist = 1
prev = int(input())
while True:
    curr = int(input())
    if curr == 0: break
    if curr == prev:
        count += 1
    else:
        if count > max_dist: max_dist = count
        count = 1
    prev = curr
print(max(max_dist, count))
```

**20. Эффективная пара (расстояние $\ge 5$)**


```Python
n = int(input())
nums = [int(input()) for _ in range(n)]
max_prod = -1
current_max_prefix = -1

for i in range(5, n):
    # Фиксируем текущий элемент nums[i]
    # Находим самый большой элемент из тех, что были 5 или более шагов назад
    if nums[i-5] > current_max_prefix:
        current_max_prefix = nums[i-5]
    
    if current_max_prefix * nums[i] > max_prod:
        max_prod = current_max_prefix * nums[i]
print(max_prod)
```

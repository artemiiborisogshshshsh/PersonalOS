# **Переменные и типы данных**
**[[переменная]]** — именованные области памяти, где хранится информация.
**Алгоритм создания:**
```Python
[имя_переменной] = [значение_переменной]

```

**Типы данных:**
- `int` — целые числа (например, 5, -10).
- `float` — числа с плавающей точкой (например, 3.14, -2.5).
- `str` — строки (текст, например, "Привет").
- `bool` — логические значения (True, False).
- `list`— списки (например, [1, 2, 3]).
- `tuple` — кортежи, неизменяемые списки (например, (1, 2, 3)).
- `dict` — словари, пары ключ-значение (например, {"ключ": "значение"}).
- `set` — множества, уникальные элементы (например, {1, 2, 3}).
**Пример:**
```Python
x = 10       # целое число
y = 3.14     # число с плавающей точкой
name = "Алиса"  # строка
is_active = True  # логическое значение
```
# **Ввод и вывод данных**
- Для ввода используется функция `input()`.
- Для вывода — функция `print()`.
**Пример:**
```Python
name = input("Введите ваше имя: ")
print("Привет,", name)
```
# **Арифметические операции**
+ — сложение.
==P.S.Сложение (конкатенация) строк в Python осуществляется тоже с помощью оператора +.==
- — вычитание.
==P.S. Умножение на целое число строки это дублирование==
/ — деление (результат — float).
// — целочисленное деление.
% — остаток от деления.
** — возведение в степень.
**Пример:**
```Python
a = 10
b = 3
print(a + b)   # 13
print(a // b)  # 3
print(a % b)   # 1
```
# Строки
## **Основные свойства строк**
1. **Строки неизменяемы**: нельзя изменить символы строки после её создания.
2. **Индексация**: доступ к символам через индекс:
• Прямая индексация: `s[0]` — первый символ.
• Обратная индексация: `s[-1]`— последний символ.
## **Срезы строк**
**Синтаксис:** строка[начало:конец:шаг] # `s[1:4:2]`
1. Примеры:
```Python
s = "Программирование"
print(s[0:5])  # Прогр
print(s[5:])   # аммирование
print(s[::-1]) # еинавориммаргорП (обратный порядок)
```
2. Параметры:
• начало — индекс, с которого начинается срез.
• конец — индекс, до которого выполняется срез (не включая). ==-1==
• шаг — шаг через который выбираются символы.
## **Основные методы и функции строк**
• `s.find("подстрока")` — индекс первого вхождения подстроки.
• `s.count("подстрока")` — количество вхождений подстроки.
• `s.replace("старое", "новое", "сколько раз(при каком вхождении")` — замена подстроки.
• `s.split("разделитель")` — разбивает строку на части по разделителю.
• `"разделитель".join(список)` — объединяет элементы списка в строку.
• `s.upper()` — все символы в верхний регистр.==(мало вероятно что понадобится)==
• `s.lower()` — все символы в нижний регистр. ==(мало вероятно что понадобится)==
• `s.capitalize()` — символ заглавный. ==(мало вероятно что понадобится)==
• `s.title()` — первые буквы каждого слова заглавные. ==(мало вероятно что понадобится)==

## **Примеры использования**
1. **Подсчет символов**
Подсчитайте количество букв "а" в строке:
```Python
s = "абракадабра"
print(s.count("а"))  # Вывод: 5
```
2. **Удаление пробелов**
Удалите все пробелы из строки:
```Python
s = "Привет, как дела?"
print(s.replace(" ", ""))  # Привет,какдела?
```
3. **Переворот строки**
Переверните строку задом наперед:
```Python
s = "abcdef"
print(s[::-1])  # fedcba
```
4. **Подсчет слов**
Найдите количество слов в строке:
```Python
s = "Это пример текста для анализа"
print(len(s.split()))  # 5
```

## **Задача на арифметические операции**
Пользователь вводит два числа. Программа должна вывести их сумму, разность, произведение и частное.
**Пример кода:**
```Python

print("Разность:", a - b)
print("Произведение:", a * b)
print("Частное:", a / b)
```

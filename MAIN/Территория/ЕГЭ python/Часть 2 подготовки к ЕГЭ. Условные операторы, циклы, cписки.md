# Условные конструкции (`if`, `else`, `elif`)

Условные конструкции позволяют выполнять разные действия в зависимости от условий.

## Условные операторы в Python бывают следующие.

- `if`: Проверяет условие. Если оно истинно (`True`), выполняет блок кода.
- `elif`: Проверяет дополнительные условия, если предыдущее условие оказалось ложным.
- `else`: Выполняет блок кода, если все предыдущие условия ложны.

### **Синтаксис:**

```Python
if условие_1:
		# выполняется, если условие_1 истинно
elif условие_2:
		# выполняется, если условие_1 ложно, но условие_2 истинно
else:
		# выполняется, если ни одно из условий не истинно
```

### Примеры:

1. **Простой** `if`**:**

```Python
number = int(input("Введите число: "))
if number > 0:
		print("Число положительное")
```

1. `if` **с** `else`**::**

```Python
age = int(input("Введите ваш возраст: "))
if age >= 18:
		print("Вы совершеннолетний.")
else:
		print("Вы несовершеннолетний.")
```

1. `if` **с** `elif` **и** `else`**::**

```Python
score = int(input("Введите оценку (0–100): "))
if score >= 90:
		print("Отлично!")
elif score >= 70:
		print("Хорошо")
elif score >= 50:
		print("Удовлетворительно")
else:
		print("Неудовлетворительно")
```

### **Операторы сравнения**

- ==: равно.
- !=: не равно.
- <, >, <=, >=: меньше, больше, меньше или равно, больше или равно.
- in он возвращает True, если одна подстрока входит в состав строки, в противном случае возвращает False.

### **Логические операторы**

- `and`: логическое И (оба условия должны быть истинными).
- `or`: логическое ИЛИ (достаточно одного истинного условия).
- `not`: логическое НЕ (инвертирует условие).

### Примеры использования `if`:

1. **Использование оператора** `**in**`

```Python
full_name = 'Мария Петрова'
search_name = 'Мария'

if search_name in full_name:
	# Проверяем, есть ли «содержимое» строки search_name в full_name
    print('Пользователь Мария есть в нашей базе данных')
else:
    print('Пользователь Мария в базе данных отсутствует')
```

1. **Использование логических операторов и операторов сравнения**

```Python
a = int(input("Введите число A: "))
b = int(input("Введите число B: "))
if a > 0 and b > 0:
		print("Оба числа положительные")
```

# Циклы

## **Цикл** `**for**`

Цикл for используется для перебора элементов последовательности (например, списка, строки) или диапазона чисел.

### **Синтаксис:**

```Python
for переменная in последовательность:
		# тело цикла
```

### **Примеры:**

1. Перебор чисел с помощью range:

```Python
for i in range(5):  # 0, 1, 2, 3, 4
		print(i)
```

1. Перебор списка:

```Python
numbers = [10, 20, 30]
for num in numbers:
		print(num)
```

1. Перебор символов строки:

```Python
text = "Python"
for char in text:
		print(char)
```

1. Перебор строки/списка

```Python
text = "Python"
for i in range(len(text)):
		print(text[i])
```

## **Цикл** `**while**`

Цикл while выполняется, пока условие истинно.

### **Синтаксис:**

```Python
while условие:
		# тело цикла
```

### **Примеры:**

1. Счетчик:

```Python
i = 0
while i < 5:
		print(i)
		i += 1
```

1. Работа с пользовательским вводом:

```Python
password = ""
while password != "1234":
    password = input("Введите пароль: ")
print("Пароль верный!")
```

## **Прерывание цикла**

- `break`: завершает цикл досрочно.
- `continue`: пропускает текущую итерацию и переходит к следующей.

### **Пример:**

```Python
for i in range(10):
		if i == 5:
				break  # завершает цикл, когда i равно 5
		if i % 2 == 0:
				continue  # пропускает четные числа
print(i)
```

# **Использование** `**else**` **с циклами**

В Python блок `else` можно использовать вместе с циклами. Он выполняется **только если цикл завершился нормально** (без использования команды `break`).

### **Синтаксис:**

```Python
for переменная in последовательность:
		# тело цикла
else:
		# выполняется, если цикл завершился без break
```

```Python
while условие:
		# тело цикла
else:
		# выполняется, если цикл завершился без break
```

### **Примеры:**

1. **Поиск элемента в списке (**`for` **+** `else`**)::**

```Python
numbers = [1, 3, 5, 7, 9]
target = 4
for num in numbers:
		if num == target:
				print(f"Число {target} найдено!")
				break
else:
		print(f"Число {target} не найдено в списке.")
```

1. **Проверка числа на простоту (**`for` **+** `else`**)::**

```Python
n = int(input("Введите число: "))
if n > 1:
    for i in range(2, n):
        if n % i == 0:
            print(f"{n} не является простым числом.")
            break
    else:
        print(f"{n} — простое число.")
else:
    print("Введите число больше 1.")
```

# Списки

Списки (`list`) используются для хранения набора значений.

### **Операции со списками:**

1. **Создание списка:**

```Python
numbers = [1, 2, 3, 4, 5]
```

1. **Обращение к элементам:**

```Python
print(numbers[0])  # 1
```

1. **Добавление элемента:**

```Python
numbers.append(6)
```

1. **Удаление элемента:**

```Python
numbers.remove(3)
```

1. **Итерация по списку:**

```Python
for num in numbers:
		print(num)
```

1. **Генератор списков**

```Python
m = [i for i in range(10)]
```

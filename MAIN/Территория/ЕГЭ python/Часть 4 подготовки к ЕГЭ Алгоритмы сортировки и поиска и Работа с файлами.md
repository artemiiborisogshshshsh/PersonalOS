# Алгоритмы сортировки и поиска

Алгоритмы сортировки и поиска данных — это фундаментальные инструменты программирования, которые широко используются в задачах ЕГЭ. Они позволяют упорядочивать данные и находить нужные элементы в массиве (или списке).

## **Сортировка**

Сортировка — это процесс упорядочивания элементов массива или списка по возрастанию или убыванию.

## Встроенная Сортировка (`sort` & `sorted`)

### **Функция** **sort()**

1. **Описание**:

• Это метод списка, который изменяет сам список (сортирует его на месте).

• Работает **только с объектами типа** `list`.

2. **Особенности**:

• Возвращает `None` (ничего не возвращает), так как сортирует список на месте.

• Сортировка производится по возрастанию по умолчанию.

3. **Синтаксис**:

```Python
list.sort(key=None, reverse=False)
```

4. **Параметры**:

• `key` (опционально): Функция, которая задаёт правило сортировки (например, длина строки или значение атрибута объекта).

• `reverse` (опционально): Если `True`, сортировка идёт в обратном порядке (по убыванию).

5. **Пример**:

```Python
numbers = [3, 1, 4, 1, 5]
numbers.sort()
print(numbers)  # [1, 1, 3, 4, 5]
# Сортировка по длине строки
words = ["apple", "banana", "kiwi"]
words.sort(key=len)
print(words)  # ['kiwi', 'apple', 'banana']
```

### **Функция sorted()**

1. **Описание**:

• Это встроенная функция [[Python]], которая возвращает **новый отсортированный объект**.

• Работает с любым **итерируемым объектом**: списками, строками, словарями, множествами и т.д.

2. **Особенности**:

• Не изменяет исходный объект.

• Возвращает новый отсортированный объект того же типа (если это список) или тип
list (если входные данные были другого типа).

3. **Синтаксис**:

```Python
sorted(iterable, key=None, reverse=False)
```

4. **Параметры**:

• `iterable`: Итерируемый объект для сортировки.

• `key` (опционально): Функция, которая задаёт правило сортировки.

• `reverse` (опционально): Если True, сортировка идёт в обратном порядке.

5. **Пример**:

```Python
numbers = [3, 1, 4, 1, 5]
sorted_numbers = sorted(numbers)
print(sorted_numbers)  # [1, 1, 3, 4, 5]
print(numbers)         # [3, 1, 4, 1, 5] (не изменился)
# Сортировка множества
unique_numbers = {10, 2, 3}
print(sorted(unique_numbers))  # [2, 3, 10]
# Сортировка строки
text = "python"
print(sorted(text))  # ['h', 'n', 'o', 'p', 't', 'y']
```

### **Сравнение** `**sort**` **и** `**sorted**`

|**Характеристика**|`sort()`|`sorted()`|
|---|---|---|
|**Тип объекта**|Только список (list)|Любой итерируемый объект|
|**Возвращаемое значение**|None (сортирует на месте)|Новый отсортированный объект|
|**Изменяет объект?**|Да|Нет|
|**Синтаксис**|list.sort(key, reverse)|sorted(iterable, key, reverse)|
|**Гибкость**|Только списки Любой тип (список, строка, множество)|

**Когда что использовать:**

• Используйте `sort()`, если вам нужно **изменить оригинальный список** и вы работаете только со списками.

• Используйте `sorted()`, если требуется **создать новый отсортированный объект**, не изменяя оригинал, или если вы работаете с чем-то, кроме списка.

### **Сортировка пузырьком** ==**(не очень нужно на ЕГЭ)**==

Мы проходим по массиву несколько раз, ==сравнивая пары== соседних элементов. Если порядок неправильный, меняем их местами.

**Код:**

```Python
def сортировка_пузырьком(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
числа = [64, 34, 25, 12, 22, 11, 90]
сортировка_пузырьком(числа)
print(числа)
```

**Объяснение:**

- Алгоритм сравнивает каждую пару соседних элементов.
- Самые большие элементы «всплывают» в конец массива.

### **Поиск**

1. **Линейный поиск**

Последовательно проходим по массиву и сравниваем каждый элемент с искомым.

**Код:**

```Python
def линейный_поиск(arr, элемент):
    for i in range(len(arr)):
        if arr[i] == элемент:
            return i
    return -1
числа = [64, 34, 25, 12, 22, 11, 90]
print(линейный_поиск(числа, 25))  # Вывод: 2
```

# Работа с файлами

### **Открытие и чтение файла**

**Код:**

```Python
# Открываем файл для чтения
with open("пример.txt", "r", encoding="utf-8") as файл:
    содержимое = файл.read()
    print(содержимое)
```

**Объяснение:**

- `open` открывает файл.
- `"r"` — режим чтения (read).
- `with` автоматически закрывает файл после завершения работы.

### **Запись в файл**

**Код:**

```Python
# Записываем данные в файл
with open("пример.txt", "w", encoding="utf-8") as файл:
    файл.write("Это текст, записанный в файл.")
```

**Объяснение:**

- `"w"` — режим записи (write), затирает предыдущие данные.
- `write` записывает текст в файл.

### **Добавление в файл**

**Код:**

```Python
# Добавляем данные в файл
with open("пример.txt", "a", encoding="utf-8") as файл:
    файл.write("\nДобавлена новая строка.")
```

**Объяснение:**

- `"a"` — режим добавления (append).

**Чтение построчно**

**Код:**

```Python
# Читаеум файл построчно
with open("пример.txt", "r", encoding="utf-8") as файл:
    for строка in файл:
        print(строка.strip())
```

**Объяснение:**

- `strip()` удаляет лишние пробелы и символы переноса строки.

**Обработка чисел в файле**

**Пример: Найти сумму всех чисел в файле:**

```Python
with open("числа.txt", "r", encoding="utf-8") as файл:
    сумма = 0
    for строка in файл:
        числа = map(int, строка.split())
        сумма += sum(числа)
    print("Сумма чисел:", сумма)
```

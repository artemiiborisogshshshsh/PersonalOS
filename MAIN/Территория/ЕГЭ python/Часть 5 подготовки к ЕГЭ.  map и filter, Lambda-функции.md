# **Функция** **map**

`map` применяется для трансформации каждого элемента в последовательности. Она принимает два аргумента:

1. Функция (включая lambda-функции), которая будет применяться к каждому элементу.
2. Итерируемый объект (список, кортеж и т.д.).
### **Пример работы:**

```Python
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # [1, 4, 9, 16]
```

**Что происходит:**

- Каждый элемент списка `numbers` передаётся в lambda-функцию.
- Результаты преобразования (квадраты) собираются в новый список.

# **Функция** **filter**

`filter` используется для отбора элементов из последовательности, соответствующих определённому условию. Она принимает два аргумента:

1. Условие в виде функции (lambda или обычной функции), которое возвращает `True` или `False`.
2. Итерируемый объект.

### **Пример работы:**

```Python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4, 6]
```

**Что происходит:**

- Каждый элемент списка `numbers` проверяется в lambda-функции на чётность.
- Только те элементы, для которых функция вернула `True`, попадают в итоговый список

> [!important] Если необходимо просто преобразовать данные — используйте `map`. Если нужно отобрать подходящие элементы — применяйте `filter`.

# **Lambda-функции**

Функции, которые определяются с помощью ключевого слова `lambda`. Они компактны и часто используются для простых операций, где нет необходимости объявлять полноценную функцию.

### **Синтаксис**

```Python
название_функции = lambda аргументы: выражение
```

Lambda-функция может содержать любое количество аргументов, но только одно выражение, результат которого возвращается.

### **Примеры:**

1. **Фильтрация данных**

Функция `filter` используется для выбора элементов, которые соответствуют определённому условию.

```Python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # [2, 4, 6]
```

2. **Трансформация данных**

Функция `map` применяется для преобразования каждого элемента в последовательности.

```Python
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # [1, 4, 9, 16]
```

3. **Сортировка по сложным критериям**

Lambda-функции удобны для задания ключа сортировки.

```Python
students = [
    {"name": "Alice", "grade": 85},
    {"name": "Bob", "grade": 70},
    {"name": "Charlie", "grade": 95}
]
sorted_students = sorted(students, key=lambda student: student["grade"])
print(sorted_students)
# [{'name': 'Bob', 'grade': 70}, {'name': 'Alice', 'grade': 85}, {'name': 'Charlie', 'grade': 95}]
```

> **Вывод:**


> [{'name': 'Bob', 'grade': 70}, {'name': 'Alice', 'grade': 85}, {'name': 'Charlie', 'grade': 95}

4. **Вызов в одном выражении**

Lambda-функция может быть вызвана сразу после определения.

```Python
result = (lambda x, y: x + y)(3, 5)
print(result)  # 8
```

# **Примеры заданий:**

## **map**

1. **Умножение на 2**

    Напишите программу, которая с помощью `map` умножает каждый элемент списка чисел на 2.

    **Решение:**

    ```Python
    numbers = [1, 2, 3, 4]
    doubled = list(map(lambda x: x * 2, numbers))
    print(doubled)  # [2, 4, 6, 8]
    ```

2. **Конвертация в строки**

    Преобразуйте список чисел в список строковых значений с использованием `map`.

    **Решение:**

    ```Python
    numbers = [1, 2, 3]
    as_strings = list(map(str, numbers))
    print(as_strings)  # ['1', '2', '3']
    ```

3. **Длина слов**

    Используя `map`, получите длину каждого слова в списке строк.

    **Решение:**

    ```Python
    words = ['apple', 'banana', 'kiwi']
    lengths = list(map(lambda word: len(word), words))
    print(lengths)  # [5, 6, 4]
    ```

4. **Преобразование в верхний регистр**

    С помощью `map` преобразуйте все строки в списке в верхний регистр.

    **Решение:**

    ```Python
    words = ['hello', 'world']
    upper_case = list(map(lambda word: word.upper(), words))
    print(upper_case)  # ['HELLO', 'WORLD']
    ```

5. **Квадрат разности**

    Используя `map`, напишите функцию, которая принимает два списка одинаковой длины и возвращает список квадратов разности их элементов.

    **Решение:**

    ```Python
    list1 = [2, 4, 6]
    list2 = [1, 3, 5]
    squared_differences = list(map(lambda x, y: (x - y) ** 2, list1, list2))
    print(squared_differences)  # [1, 1, 1]
    ```


## **filter**

1. **Фильтрация чётных чисел**

    Напишите программу, которая с помощью `filter` оставляет только чётные числа из списка.

    **Решение:**

    ```Python
    numbers = [1, 2, 3, 4, 5, 6]
    even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
    print(even_numbers)  # [2, 4, 6]
    ```

2. **Фильтрация строк по длине**

    Отфильтруйте строки длиной более 4 символов.

    **Решение:**

    ```Python
    words = ['cat', 'elephant', 'dog', 'tiger']
    long_words = list(filter(lambda word: len(word) > 4, words))
    print(long_words)  # ['elephant', 'tiger']
    ```

3. **Фильтрация положительных чисел**

    Используя `filter`, выберите из списка только положительные числа.

    **Решение:**

    ```Python
    numbers = [-10, -5, 0, 5, 10]
    positive_numbers = list(filter(lambda x: x > 0, numbers))
    print(positive_numbers)  # [5, 10]
    ```

4. **Фильтрация слов, начинающихся с определённой буквы**

    Отфильтруйте слова, которые начинаются на букву "A" или "a".

    **Решение:**

    ```Python
    words = ['apple', 'banana', 'apricot', 'cherry']
    starts_with_a = list(filter(lambda word: word.lower().startswith('a'), words))
    print(starts_with_a)  # ['apple', 'apricot']
    ```

5. **Числа, делящиеся на 3**

    Напишите программу, которая с помощью `filter` выбирает из списка только числа, делящиеся на 3 без остатка.

    **Решение:**

    ```Python
    numbers = [1, 3, 4, 6, 7, 9]
    divisible_by_three = list(filter(lambda x: x % 3 == 0, numbers))
    print(divisible_by_three)  # [3, 6, 9]
    ```


## **Lambda-функции**

1. Lambda-функция для проверки, является ли число чётным

```Python
is_even = lambda x: x % 2 == 0
print(is_even(4))  # True
print(is_even(7))  # False
```

2. Фильтрация списка слов длиной более 3 символов

```Python
words = ["cat", "dog", "apple", "hi", "banana"]
filtered_words = list(filter(lambda word: len(word) > 3, words))
print(filtered_words)  # ['apple', 'banana']
```

3. Lambda-функция, которая возвращает сумму квадратов двух чисел

```Python
sum_of_squares = lambda x, y: x**2 + y**2
print(sum_of_squares(3, 4))  # 25
```

4. Преобразование списка чисел в их кубы с использованием `map`

```Python
numbers = [1, 2, 3, 4]
cubes = list(map(lambda x: x**3, numbers))
print(cubes)  # [1, 8, 27, 64]
```

5. Сортировка списка кортежей (имя, возраст) по возрасту

```Python
people = [("Alice", 30), ("Bob", 25), ("Charlie", 35)]
sorted_people = sorted(people, key=lambda person: person[1])
print(sorted_people)  # [('Bob', 25), ('Alice', 30), ('Charlie', 35)]
```

Функции all() и any() предназначены для работы с итерируемыми объектами (списками, кортежами, множествами и т. д.) и выполняют логические операции:

- all(iterable): возвращает True, если **все** элементы iterable являются истинными (или iterable пуст).
- any(iterable): возвращает True, если **хотя бы один** элемент iterable является истинным.

В Python логические значения True и False эквивалентны 1 и 0, а также любая ненулевая или непустая структура считается True.

**Таблица истинности функций:**

|   |   |   |
|---|---|---|
|**Входной список**|all()|any()|
|[True, True, True]|True|True|
|[True, False, True]|False|True|
|[False, False, False]|False|False|
|[] (пустой)|True|False|

**Примеры**

**Проверка всех элементов списка**

Допустим, у нас есть список оценок (True, если оценка ≥ 3, False, если 2 и ниже):

```Python
grades = [True, True, False, True]
print(all(grades))  # False (не все оценки хорошие)
print(any(grades))  # True (хотя бы одна хорошая оценка есть)
```

**Проверка строки на заглавные буквы**

```Python
text = "HELLO"
print(all(c.isupper() for c in text))  # True (все буквы заглавные)
```

**Проверка, есть ли четные числа в списке**

```Python
numbers = [1, 3, 5, 7, 9]
print(any(n % 2 == 0 for n in numbers))  # False (четных чисел нет)
```

**📘 Разбор номеров для подготовки к ЕГЭ**

**🔹 Задача 1 (анализ списка)**

Дан список чисел. Нужно проверить, являются ли **все** числа положительными.

**Решение:**

```Python
nums = [5, 8, 3, 9, 2]
print(all(n > 0 for n in nums))  # True, если все числа > 0
```

📌 **Объяснение**: проверяем условие n > 0 для каждого элемента.

**🔹 Задача 2 (поиск хотя бы одного простого числа)**

Дан список чисел. Проверить, есть ли среди них хотя бы одно простое число.

**Решение:**

```Python
def is_prime(n):
	if n < 2:
		return False
	return all(n % d != 0 for d in range(2, int(n**0.5) + 1))
nums = [10, 15, 20, 23, 30]
print(any(is_prime(n) for n in nums))  # True (23 - простое)
```

📌 **Объяснение**: функция is_prime() проверяет простоту числа, а any() определяет, есть ли хотя бы одно простое число.

**🔹 Задача 3 (поиск слов с заглавной буквы)**

Дан список слов. Проверить, есть ли хотя бы одно слово, начинающееся с заглавной буквы.

**Решение:**

```Python
words = ["apple", "Banana", "cherry"]
print(any(word[0].isupper() for word in words))  # True (есть "Banana")
```

📌 **Объяснение**: word[0].isupper() проверяет, начинается ли слово с заглавной буквы.

## Ежедневный видео отчет
### Цель
Создать объективную, живую, ежедневную хронику лагерной жизни, демонстрирующую участие всех детей и реальную атмосферу смены, также для верификации информации в случае возникновения непредвиденных ситуаций.
*Видео должно быть отправлено до 16:30, но лучше отправлять сразу после мероприятия, в видео должна быть показана активность, и обратная связь от детей, каждый раз лучше выбирать разных детей чтобы картина складывалась объективно.*
### План съемок для одного отряда

| **Мероприятие**               | **Обязательное условие (по умолчанию 1 отзыв)** |
| ----------------------------- | ----------------------------------------------- |
| Завтрак / обед                | Минимум 1 видео в столовой                      |
| Утренняя зарядка              | Общий план                                      |
| Внутренние мероприятия отряда | Отрядная активность                             |
| Общелагерное мероприятие      | Общий план, эмоции, 1–2 отзыва                  |
| Выездные экскурсии            | Дорога + локация + 1-2 отзыва                   |
### Распределение обязанностей
#### Ответственный за видео от отряда:
- Вожатый. 
- Снимает: вертикально, 30–60 секунд.
- Обязательно записывает:  
    ▪ кадры действий  
    ▪ минимум 1 комментарий ребёнка («что делали? понравилось? почему?»)
- Нужно вести список уже интервьюируемых чтобы не повторялись
#### Медиа-куратор:
- Принимает видео в Telegram.
- Проверяет: наличие лиц, звука, соответствие плану.
- Ведет Чек-лист. 
#### Рекомендации по интервью:
- Вопросы:  
    ▪ «Что делали?»  
    ▪ «Что больше всего понравилось?»  
    ▪ «Чему научился сегодня?»  
    ▪ «Что бы ты изменил?»
- Старайтесь чередовать активных и тихих детей.
## Чек-лист
### Шкала
- **1–3** — слабо реализовано / требует серьёзных доработок
- **4–6** — реализовано частично / удовлетворительно
- **7–8** — хорошо реализовано
- **9–10** — отлично / превосходно реализовано
### Критерии со стороны ребёнка

| Критерий                 | Описание                                         | Балл |
| ------------------------ | ------------------------------------------------ | ---- |
| Интерес                  | Дети увлечены, активно включены в процесс        |      |
| Понимание цели           | Дети понимают, зачем участвуют в активности      |      |
| Обучающая ценность       | Ребёнок получает новые знания/опыт               |      |
| Уровень вовлечённости    | Большинство детей задействовано, нет «пассивных» |      |
| Эмоциональный отклик     | Дети радуются, смеются, гордятся собой           |      |
| Безопасность для ребёнка | Все действия и материалы безопасны               |      |

### Критерии со стороны вожатого

| Критерий                | Описание                                                      | Балл |
| ----------------------- | ------------------------------------------------------------- | ---- |
| Подготовленность        | Материалы, задания, реквизит готовы заранее                   |      |
| Пояснение задания       | Указания были понятны детям, не вызывали путаницу             |      |
| Контакт с детьми        | Вожатый на одной волне с детьми, умеет слушать и поддерживать |      |
| Работа с группой        | Вовлекает всех, не теряет контроль, управляет процессом       |      |
| Гибкость                | Умеет адаптировать ход мероприятия по ходу (если нужно)       |      |
| Поддержка помощника     | Взаимодействие с помощником слаженное и корректное            |      |
| Педагогическая цель     | Чётко видна обучающая задача и как она реализована            |      |
| Энергия и вовлечённость | Вожатый сам в игре, «горит» процессом, заряжает детей         |      |

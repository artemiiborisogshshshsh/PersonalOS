## **Лекция: Введение в олимпиадное программирование**
#### Python vs C++ в олимпиадах

|Характеристика|Python|C++|
|---|---|---|
|Скорость выполнения|Медленнее (~5–10x)|Очень быстрая|
|Удобство синтаксиса|Прост для новичков|Нужна аккуратность|
|Работа с большими числами|Автоматически (`int`)|Ограничен `int`/`long long`|
|STL / библиотеки|Есть `collections`, `heapq`|Есть `set`, `map`, `vector`|
|На IOI / ВОШ чаще всего|Иногда допустим|Рекомендуется/обязателен|

## Примерные шаблоны

### C++ шаблон

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
#define fast_io ios::sync_with_stdio(false); cin.tie(nullptr);

int32_t main() {
    fast_io
    int n;
    cin >> n;
    cout << n * n << '\n';
}
```

Объяснение:
- `#include <bits/stdc++.h>` — подключает все стандартные библиотеки.
- `#define int long long` — чтобы избежать переполнения.
- `fast_io` — ускоряет ввод/вывод.

###  Python шаблон

```python
import sys

def input():
    return sys.stdin.readline().rstrip()

n = int(input())
print(n * n)
```

 Объяснение:

- `sys.stdin.readline()` — намного быстрее обычного `input()`.

### Задание 1. Сумма чисел

**Вход:** одно число n, затем n чисел  
**Выход:** сумма чисел

Python:

```python
n = int(input())
a = list(map(int, input().split()))
print(sum(a))
```

 C++:

```cpp
int n; cin >> n;
int sum = 0;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    sum += x;
}
cout << sum << '\n';
```

| Этап                                              | Действия                                                                                                                                                                                                     | Цель / Результат                                           |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| **1. Установка Windows 11 (эталонная машина)**    | • Установить Windows 11 Pro x64 с ISO от Microsoft<br>• Создать локальную учётную запись (например, `adminlocal`)<br>• Не подключаться к интернету, пока не отключена телеметрия                             | Чистая база без мусора и лишних приложений                 |
| **2. Установка необходимого ПО**                  | • Word, Excel<br>• Python 3.13 + PyCharm<br>• Scratch<br>• Unity Hub + Unity 2020<br>• Discord + Zapret                                                                                                      | Рабочее окружение для всех пользователей                   |
| **3. Установка и настройка Kaspersky Free**       | • Скачать: [https://www.kaspersky.ru/free-antivirus](https://www.kaspersky.ru/free-antivirus)<br>• Войти в Kaspersky Account<br>• Включить автообновления и самозащиту<br>• Отключить рекламу и рекомендации | Защита от вирусов, без лишней нагрузки                     |
| **4. Автоматическая очистка системы (вариант 1)** | **Параметры → Система → Хранилище → Контроль памяти**<br>Включить очистку временных файлов раз в неделю                                                                                                      | Система не засоряется кэшем                                |
| **4.1. Автоочистка (вариант 2 — через скрипт)**   | Создать `clean_cache.bat`:<br>```bat<br>del /s /q "%temp%\*"<br>del /s /q "C:\Windows\Temp\*"<br>cleanmgr /sagerun:1<br>```<br>Добавить в Планировщик заданий при старте системы                             | Автоматическая очистка при каждом запуске                  |
| **5. Подготовка драйверов**                       | • Установить все нужные драйверы на эталонном ПК<br>• В PowerShell:<br>```powershell<br>pnputil /export-driver * C:\DriversBackup<br>```                                                                     | Сбор всех драйверов для автоустановки                      |
| **6. Автоустановка драйверов после клонирования** | Создать `install_drivers.bat`:<br>```bat<br>pnputil /add-driver "C:\DriversBackup\*.inf" /subdirs /install<br>```<br>Добавить в автозапуск или в Autounattend                                                | При первом запуске ставятся все драйверы                   |
| **7. Очистка перед созданием образа**             | • Удалить временные файлы и профили<br>• Выполнить:<br>```cmd<br>sysprep /generalize /oobe /shutdown<br>```                                                                                                  | Подготовка системы к клонированию                          |
| **8. Создание образа системы (.wim)**             | Через DISM:<br>```cmd<br>dism /capture-image /imagefile:D:\Win11Unified.wim /capturedir:C:\ /name:"UnifiedWin11"<br>```<br>или через Acronis / Macrium Reflect                                               | Создан единый универсальный образ системы                  |
| **9. Развёртывание образа**                       | **Вариант 1:** заменить `install.wim` на флешке<br>**Вариант 2:** через PXE / WDS по сети                                                                                                                    | Быстрая установка системы на все ПК                        |
| **10. Финальные действия после установки**        | • Проверить активацию Windows<br>• Проверить Unity, PyCharm, Scratch<br>• Убедиться, что Kaspersky обновляется<br>• Проверить автозапуск очистки и драйверов                                                 | Система полностью готова и поддерживает себя автоматически |

# PersonalOS

Personal Academic OS: Telegram-first планировщик для студента ТПУ.

Каждое номерное обновление включает новую пользовательскую возможность вместе
с исправлениями и готовится в отдельной ветке. Субботний цикл, срочные патчи
в `main` и календарь возможностей: [план еженедельных выпусков](docs/WEEKLY_RELEASE_PLAN.md).

[Обновление 1 — учебный цикл, конспекты и пробный период](docs/UPDATE_1.md).

Статус реализации и последовательный roadmap: [docs/MVP_AUDIT_AND_ROADMAP_2026-09-16.md](docs/MVP_AUDIT_AND_ROADMAP_2026-09-16.md).

Ручные sandbox-проверки, которые не входят в synthetic suite: [docs/P2_MANUAL_ACCEPTANCE_CHECKLIST.md](docs/P2_MANUAL_ACCEPTANCE_CHECKLIST.md).

Процесс promotion двух invite-only ботов через staging и production: [docs/BOT_RELEASE_WORKFLOW.md](docs/BOT_RELEASE_WORKFLOW.md).

Настройка opt-in анонсов после подтверждённого релиза: [docs/RELEASE_ANNOUNCEMENTS.md](docs/RELEASE_ANNOUNCEMENTS.md). Возможность реализована, но live success hook и credentials пока не настроены.

До последнего подтверждения записей Google не было. Свежая сверка подтвердила 7 событий; лекция сохранена, выполненной не отмечена.

## Исправления по результатам прохождения

- Подсказка настройки профиля ведёт по кнопкам сна и дороги.
- Завершение настройки больше не утверждает, что первый план уже готов; доступны посещаемость и главное меню.

- Успешная первоначальная публикация предлагает кнопки проверки плана, материалов и главного меню вместо команды.

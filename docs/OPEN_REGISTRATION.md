# Открытая регистрация

Обычный запуск `scripts/invited_beta_bot.py run` открывает регистрацию по `/start` в личном чате. Ключи и ручное приглашение не нужны. Бот сохраняет отдельную запись доступа и поколение для каждого Telegram ID; блокировка через `revoke` сохраняется и не снимается повторным `/start`. Для прежнего закрытого режима добавьте `--invite-only`.

Пробный период — 21 день с первой успешной публикации плана. OAuth подключается каждым пользователем отдельно. Публичный запуск требует отдельной проверки аудитории именно production-проекта Google OAuth; снятие ограничения Telegram не переводит Google из Testing в Production. Оплата и импорт расписания по фото отключены; фото конспектов доступны.
